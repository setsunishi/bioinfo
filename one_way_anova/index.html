🌟 本回の2大「Wow!（納得・発見）」体験

多重比較の検出力と、t検定×分散分析の数学的なつながりを体感する
【Wow体験 ①】

⚡ 6群15ペアの総当たりで体感する「多重性の壁」と手法による検出力の違い

6種類の飼料（niwatori.csv）を総当たり比較すると $\binom{6}{2} = 15\text{通り}$ ものペアが生まれます。もし補正なしのt検定を15回繰り返すと、本当は差がなくても $1 - 0.95^{15} \approx \mathbf{53.7\%}$（半分以上の確率！）で偽陽性が出てしまいます。

Tukey-Kramer vs Bonferroni vs Holm vs Dunnett を比べると…
・ニワトリ6群では3手法とも有意ペアは8通り、CLDも casein="a", sun_ower="a", meatmeal="ac", linseed="bc", soybean="c", horsebean="b" で一致しますが、各ペアの $p$値は常に Holm法 $\le$ Bonferroni法（例：`meatmeal - horsebean` で Bonferroni $p=0.000112$ vs Holm $p=0.0000897$）！
・さらにトマト糖度例題では、総当たり（Tukey：6ペア補正）では BonePowder vs NoFertilizer が $p=0.071$ で有意にならないのに、対照区との比較に絞った Dunnett法（3ペア補正）では $p=0.041 (<0.05)$ で有意差が検出される！
【Wow体験 ②】

🔗 実は同じ検定だった？！ 2群における「$t^2 = F$」の完全一致

第8回のイネ茎葉重減少量データ（kadai2_t_vs_ANOVA.csv：Genotype A vs B）に対して、前回の「独立2群のt検定」と今回の「1元配置分散分析（ANOVA）」の両方を実行してみると…？

驚きの数学的同値性（発展課題5で検証！）：
・等分散仮定：Studentの $t = -4.7593 \implies \mathbf{t^2 = 22.651}$。なんと aov() の $F\text{値} = 22.651$ と完全一致し、$p\text{値} = 9.394 \times 10^{-6}$ もピタリと同じ！
・等分散を仮定しない場合：Welchの $t = -4.9457 \implies \mathbf{t^2 = 24.460}$。こちらも oneway.test() の $F\text{値} = 24.460$、$p\text{値} = 9.193 \times 10^{-6}$ と小数点以下まで完全一致！
$\rightarrow$ 「1元配置分散分析とは、2標本t検定を3群以上へと自然に一般化した姿である」ことが数理と実感でつながります！

📐 理論の3本柱（変動の分割・多重比較・Compact Letter Display）

多群比較を支える統計ロジック

1. なぜ平均の比較なのに「分散分析」？

データ全体のばらつき（総平方和 $S_T$）を、「群間のばらつき（平均の分散 $V_A$：シグナル）」と「群内のばらつき（分散の平均 $V_R$：誤差ノイズ）」に分割し、その比 $F = V_A / V_R$ が $1$ より有意に大きいかを片側 $F$検定で調べる！

2. 多重比較の4大手法の使い分け

・Tukey-Kramer法：全ペア総当たり比較の王道（検出力が高い）。
・Bonferroni法：有意水準をペア数 $m$ で割る（保守的・5群以上では検出力低下）。
・Holm法：$p$値が小さい順に段階的に補正しBonferroniの弱点を改良。
・Dunnett法：1つの対照群（Control）と他群の「1対多」比較に特化！

3. アルファベット表記（CLD）のルール

論文のグラフでよく見る a, b, c の文字（Compact Letter Display）。
「同じ文字を1つでも共有していれば有意差なし、共通の文字がなければ有意差あり（$p < 0.05$）」！
例："a" と "ac" は a を共有するので差なし。"a" と "bc" は共有文字がないので有意差あり！

niwatori <- read.csv("niwatori.csv", stringsAsFactors = TRUE) summary(niwatori) # 箱ひげ図＋ドットプロット boxplot(niwatori$Taiju ~ niwatori$Esa, ylab = "Weight (g)", xlab = "Feed (Esa)") stripchart(niwatori$Taiju ~ niwatori$Esa, vertical = TRUE, method = "jitter", add = TRUE) # 各群の正規性の検定（Shapiro-Wilk検定） tapply(niwatori$Taiju, niwatori$Esa, shapiro.test) # 3群以上の等分散性の検定（Bartlett検定） tapply(niwatori$Taiju, niwatori$Esa, var) bartlett.test(Taiju ~ Esa, data = niwatori)

課題2: 1元配置分散分析（等分散仮定 aov ＆ 等分散を仮定しない oneway.test）

# 群ごとの平均値を確認 tapply(niwatori$Taiju, niwatori$Esa, mean) # ① 等分散を仮定した1元配置分散分析（分散分析表の表示） anova_result <- aov(Taiju ~ Esa, data = niwatori) summary(anova_result) # ② 等分散を仮定しないWelchの1元配置分散分析 oneway.test(Taiju ~ Esa, data = niwatori, var.equal = FALSE)

課題3: Tukey-Kramer法による多重比較と Compact Letter Display (CLD)

# R標準のTukeyHSDによる全15ペアの多重比較 TukeyHSD(anova_result, "Esa", ordered = TRUE) # multcompパッケージを用いたTukey-Kramer検定とCLD（アルファベット表記）の付与 library(multcomp) tukey_result <- glht(anova_result, linfct = mcp(Esa = "Tukey")) summary(tukey_result) cld(tukey_result) # 上部マージンを広げてCLD付き箱ひげ図を描画 par(mar = c(5.1, 4.1, 6, 2.1)) plot(cld(tukey_result))

発展課題4: Bonferroni法とHolm法による多重比較と検出力の比較

# ① Bonferroni法（p値をペア数15で一律補正） pairwise.t.test(niwatori$Taiju, niwatori$Esa, p.adjust.method = "bonferroni") bonf_summary <- summary(glht(anova_result, linfct = mcp(Esa = "Tukey")), test = adjusted("bonferroni")) bonf_summary cld(bonf_summary) # ② Holm法（p値が小さい順に段階的に補正） pairwise.t.test(niwatori$Taiju, niwatori$Esa, p.adjust.method = "holm") holm_summary <- summary(glht(anova_result, linfct = mcp(Esa = "Tukey")), test = adjusted("holm")) holm_summary cld(holm_summary)

発展課題5: 2群比較における t検定と1-way ANOVA の同値性検証（kadai2_t_vs_ANOVA.csv）

dataset <- read.csv("kadai2_t_vs_ANOVA.csv", stringsAsFactors = TRUE) # (1) 等分散仮定のStudentのt検定と t^2 の計算 x_eq <- t.test(SW5_35 ~ Genotype, data = dataset, alternative = "two.sided", var.equal = TRUE) x_eq as.numeric(x_eq$statistic^2) # t値の2乗 # (2) 等分散仮定の1元配置分散分析 (aov) -> F値とp値を(1)と比較！ summary(aov(SW5_35 ~ Genotype, data = dataset)) # (3) 等分散を仮定しないWelchのt検定と t^2 の計算 x_welch <- t.test(SW5_35 ~ Genotype, data = dataset, alternative = "two.sided", var.equal = FALSE) x_welch as.numeric(x_welch$statistic^2) # t値の2乗 # (4) 等分散を仮定しないWelchのANOVA (oneway.test) -> F値とp値を(3)と比較！ oneway.test(SW5_35 ~ Genotype, data = dataset, var.equal = FALSE)

❓ よくある質問とトラブルシューティング

エラーが出たときはここを確認

⚠️ there is no package called 'multcomp' エラー

多重比較とCLD出力用のパッケージがまだインストールされていません。
RStudioのConsoleで install.packages("multcomp")（および必要に応じて install.packages("nortest")）を1回実行してから library(multcomp) を実行してください。

⚠️ glht() で not a factor エラーが出る

グループ列（Esa や Fertilizer）が文字列（character）のままになっています。
読み込み時に stringsAsFactors = TRUE を指定するか、niwatori$Esa <- as.factor(niwatori$Esa) を実行して因子（factor）に変換してから aov() と glht() を実行してください。

⚠️ plot(cld(...)) で上のアルファベット文字が見切れる

Rのデフォルトのグラフ上部余白（マージン）が狭いためです。
plot() の直前に par(mar = c(5.1, 4.1, 6, 2.1)) を実行して、第3引数（上マージン）をデフォルトの 4.1 から 6 に広げると綺麗に文字が表示されます。

⚠️ cannot open file 'niwatori.csv' エラー

作業ディレクトリ（Working Directory）がファイルの保存場所と一致していません。
RStudio メニューの Session → Set Working Directory → Choose Directory... で、ダウンロードした niwatori.csv があるフォルダを選択してください。
