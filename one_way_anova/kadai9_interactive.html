RStudioで以下のコードを実行し、箱ひげ図＋ドットプロットを描画した上で、各飼料グループの正規性検定（shapiro.test）と6群の等分散性検定（bartlett.test）の結果を入力してください。

niwatori <- read.csv("niwatori.csv", stringsAsFactors = TRUE) summary(niwatori) # (1)(2) 箱ひげ図＋ドットプロット boxplot(niwatori$Taiju ~ niwatori$Esa, ylab = "Weight (g)", xlab = "Feed (Esa)") stripchart(niwatori$Taiju ~ niwatori$Esa, vertical = TRUE, method = "jitter", add = TRUE) # (3) 各群の正規性の検定（Shapiro-Wilk検定） tapply(niwatori$Taiju, niwatori$Esa, shapiro.test) # (4) 6群の等分散性の検定（Bartlett検定） tapply(niwatori$Taiju, niwatori$Esa, var) bartlett.test(Taiju ~ Esa, data = niwatori)

課題3：Tukey-Kramer法による多重比較と Compact Letter Display (CLD)

多重比較（20点）

TukeyHSD() および multcomp パッケージの glht()・cld() を実行し、総当たり比較ペア数、有意（$p < 0.05$）となった組み合わせの数、およびCLD文字を入力してください。

# R標準のTukeyHSDで全ペアの調整済みp値 (p adj) を確認 TukeyHSD(aov(Taiju ~ Esa, data = niwatori), "Esa", ordered = TRUE) # multcompパッケージでCLD (a, b, c...) を出力し箱ひげ図に描画 library(multcomp) anova_result <- aov(Taiju ~ Esa, data = niwatori) tukey_result <- glht(anova_result, linfct = mcp(Esa = "Tukey")) summary(tukey_result) cld(tukey_result) par(mar = c(5.1, 4.1, 6, 2.1)) plot(cld(tukey_result))

発展課題4【Wow①：Bonferroni法とHolm法による多重比較と検出力の比較】

探究課題（20点）
問い： ニワトリ飼料データに対して Bonferroni法（一律15倍補正） と Holm法（段階的補正：$\times 15, \times 14, \dots$） で多重比較およびCLD付与を行い、特に soybean と casein の比較（soybean - casein：8番目に $p$値が小さいペア）の調整済み $p$値を比較して、補正アルゴリズムによる検出力の違いを確認してください（※ pairwise.t.test() の表と summary(glht(...)) の出力は同じ調整済み $p$値になります）。
# ① Bonferroni法による多重比較とCLD pairwise.t.test(niwatori$Taiju, niwatori$Esa, p.adjust.method = "bonferroni") bonf_summary <- summary(glht(anova_result, linfct = mcp(Esa = "Tukey")), test = adjusted("bonferroni")) bonf_summary cld(bonf_summary) par(mar = c(5.1, 4.1, 6, 2.1)) plot(cld(bonf_summary)) # ② Holm法による多重比較とCLD pairwise.t.test(niwatori$Taiju, niwatori$Esa, p.adjust.method = "holm") holm_summary <- summary(glht(anova_result, linfct = mcp(Esa = "Tukey")), test = adjusted("holm")) holm_summary cld(holm_summary) par(mar = c(5.1, 4.1, 6, 2.1)) plot(cld(holm_summary))
💡 発展コラム（参考）：遺伝子発現解析（RNA-seq）など大規模データで使われる FDR（BH法）と使い分けの鉄則
数千〜数万個の遺伝子を同時に検定するバイオインフォマティクス解析では、FWER制御（BonferroniやHolm）では補正が厳しく真の差まで検出しにくくなるため、「有意と判定した中に混じる偽陽性の割合（FDR：偽発見率）の期待値」を5%以下に抑える Benjamini-Hochberg（BH）法（$p_{\text{FDR}} = p_{(k)} \times \frac{m}{k}$）が標準的に使われます（Rでは p.adjust.method = "fdr" で実行可能）。
⚠️ 使い分けの鉄則：本課題のような通常の3〜6群の実験では必ず FWER制御（Tukey-Kramer法やDunnett法）を使います（少数群の実験に安易にFDRを使うと偽陽性が混じりやすくなるため、数百〜数万個のスクリーニング実験と明確に使い分けます）。

発展課題5【Wow②：2群比較における独立t検定と1-way ANOVAの同値性（$t^2 = F$）】

探究課題（20点）
問い： 前回のイネ茎葉重減少量データ（kadai2_t_vs_ANOVA.csv：Genotype A vs B の2群）に対して、
(1) 等分散仮定のt検定 と (2) 等分散仮定の1-way ANOVA（aov）、および
(3) Welchのt検定 と (4) WelchのANOVA（oneway.test）を実行し、$t$値の2乗（$t^2$）と $F$値、および $p$値の関係を検証してください。
dataset <- read.csv("kadai2_t_vs_ANOVA.csv", stringsAsFactors = TRUE) # (1) 等分散仮定のt検定 と t^2 vs (2) 等分散仮定の1-way ANOVA (aov) x_eq <- t.test(SW5_35 ~ Genotype, data = dataset, alternative = "two.sided", var.equal = TRUE) x_eq as.numeric(x_eq$statistic^2) # t^2 summary(aov(SW5_35 ~ Genotype, data = dataset)) # (3) Welchのt検定 と t^2 vs (4) Welchの1-way ANOVA (oneway.test) x_welch <- t.test(SW5_35 ~ Genotype, data = dataset, alternative = "two.sided", var.equal = FALSE) x_welch as.numeric(x_welch$statistic^2) # t^2 oneway.test(SW5_35 ~ Genotype, data = dataset, var.equal = FALSE)
