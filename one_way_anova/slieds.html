3群以上（多群）の実験デザイン

  • 要因（Factor）：群を分ける分類条件（例：肥料の種類、飼料の種類、薬剤濃度）
  • 水準（Level）：要因の中の各グループ（例：無肥料・油粕・骨粉・化学肥料の4水準＝4群）
  • 1元配置（One-way）：注目する要因が1つだけで、その中に3群以上の独立したグループがある実験配置！
🤔 疑問：「3群（A, B, C）や 6群（A〜F）あるとき、2群ずつの t.test() を総当たりで何回も繰り返せばいいのでは？」 $\rightarrow$ 実はそこに「多重検定の罠（偽陽性の急増）」という大きな落とし穴があります！
理論最重要

多群の比較に「単純なt検定の繰り返し」を使えない理由

検定を繰り返すたびに「少なくとも1回は誤って有意になる確率（FWER）」が膨れ上がる！

3群（A, B, C）で t検定を3回繰り返すと…

・総当たりペアは A vs B、B vs C、A vs C の3通り。
・もし本当は3群すべて母平均が同じ（差がゼロ）だとしても、1回の検定（有意水準 $\alpha = 0.05$）で「正しく差がない」と判定される確率は $0.95$（95%）。
・各検定が独立と仮定すると、3回とも間違えない確率は $(0.95)^3 \approx 0.857$（85.7%）。
・すると、少なくとも1ペアで誤って「有意差あり！」と偽陽性が出る確率（FWER）は：

$$1 - (1 - 0.05)^3 = 1 - 0.95^3 \approx \mathbf{14.3\%}$$

5%以下に抑えるつもりが約3倍近く（10%超）に膨らんでしまう！（※共通群を含むため完全な独立ではないが、同様に大きく上昇する）

群数 $a$ と偽陽性発生確率（FWER）の上昇（独立仮定での概算）

群数 $a$ 総当たり数 $m = \binom{a}{2}$ 全ペア非棄却 $0.95^m$ 少なくとも1回偽陽性が出る確率
2群 1 通り 95.0% 5.0%（本来の基準）
3群 3 通り 85.7% 約 14.3%
4群（トマト練習） 6 通り 73.5% 約 26.5%（4回に1回以上）
5群 10 通り 59.9% 約 40.1%
6群（ニワトリ課題） 15 通り 46.3% 約 53.7%（2回に1回以上偽陽性が混じる）
理論

多群比較の2つのアプローチ：分散分析（ANOVA）と多重比較

「全体として差があるか」を見るANOVAと、「どのペアに差があるか」を特定する多重比較

① 1元配置分散分析（One-way ANOVA）

  • 問い：「多群データの全体のどこかに平均値の差（要因の効果）があるか？」
  • 帰無仮説 $H_0$：$\mu_1 = \mu_2 = \dots = \mu_a$（全群の母平均が等しい）
  • 対立仮説 $H_1$：少なくとも1つの群の母平均が異なる
  • 特徴：1回の $F$検定で全体の差の有無を判定できるが、具体的にどの群とどの群が違うかは特定できない。

② 多重比較（Multiple Comparisons）

  • 問い：「多群データのどのグループとどのグループの間に有意な差があるのか？」
  • 仕組み：比較回数に応じて膨らむ第1種過誤（FWER）を、全体で5%以下になるよう補正してペアごとに検定する。
  • 代表手法：Tukey-Kramer法、Bonferroni法、Holm法（以上は総当たり）、Dunnett法（対照群との比較）。

💡 分散分析と多重比較の関係について
Tukey-Kramer法やDunnett法のように、それ自体で全体の第1種過誤（FWER）を5%以下に制御できる手法は、事前検定としてANOVAを行わずに直接適用しても統計学的に妥当とされています。一方、データ全体の変動を要因別に分解・評価するANOVAは多群解析の基礎（次回の2元配置分散分析の土台）となるため、論文や本演習ではANOVAと多重比較の両方を学びます。

理論の核心

なぜ「平均」の比較なのに「分散分析（ANOVA）」なのか？

全体のばらつきを「群間のばらつき（平均の分散）」と「群内のばらつき（分散の平均）」に分割する！

群間変動 $\rightarrow$ 「平均の分散 $V_A$」（シグナル＋誤差）

・各群の平均値 $\bar{X}_1, \bar{X}_2, \dots, \bar{X}_a$ が全体平均 $\bar{X}$ からどれくらい離れているか（群間平均平方 $V_A$）。
・要因（飼料や肥料の違い）によって生じたばらつきを反映する！

群内変動 $\rightarrow$ 「分散の平均 $V_R$」（誤差ノイズ）

・同じグループ内での個体ごとのばらつきを全群でプールした平均（群内平均平方・残差分散 $V_R$）。
・同じ条件でも生じる純粋な実験誤差（個体差ノイズ）を表す！

理論

変動（平方和）と自由度の分割イメージ

総平方和 $S_T$ ＝ 群間平方和 $S_A$ ＋ 群内（残差）平方和 $S_R$
総変動（総平方和 $S_T$） ｜ 総自由度 $df_T = N - 1$
全データ $X_{ij}$ と全体平均 $\bar{X}$ の差の2乗和：$\sum_{i=1}^{a}\sum_{j=1}^{n_i}(X_{ij} - \bar{X})^2$
① 群間変動（要因平方和 $S_A$）
群間自由度 $df_A = a - 1$（群数 $- 1$）
群間平均平方（平均の分散） $V_A = \dfrac{S_A}{a - 1}$ 【分子】
＋
② 群内変動（残差平方和 $S_R$ / Residuals）
群内自由度 $df_R = N - a$（全データ数 $-$ 群数）
群内平均平方（誤差分散） $V_R = \dfrac{S_R}{N - a}$ 【分母】
平方和（Sum of Squares）の恒等式
$$S_T = S_A + S_R$$
分散比 $F$（群間平均平方 $\div$ 群内誤差分散）
$$F = \frac{V_A\text{（群間分散）}}{V_R\text{（誤差分散）}} = \frac{S_A / (a - 1)}{S_R / (N - a)}$$
理論

分散分析表（ANOVA Table）と2つのF検定の違い

Rの summary(aov(Y ~ X)) の出力表と、第8回・第9回の $F$分布の役割
要因（R出力の行名） 自由度 Df 平方和 Sum Sq 平均平方（不偏分散）Mean Sq 分散比 F value $p$値 Pr(>F)
群間変動（要因列 Esa 等） $df_A = a - 1$ $S_A$ $V_A = S_A / (a - 1)$ $F = V_A / V_R$ $F(a-1, N-a)$ の上側確率
群内変動（残差 Residuals） $df_R = N - a$ $S_R$ $V_R = S_R / (N - a)$ — —

第8回の $F$検定（var.test：等分散性検定）

・2群の「分散が等しいか」を検定（$F = s_1^2 / s_2^2$）。
・どちらの分散が大きくても不等分散なので両側検定。
・$p > 0.05$ なら「等分散性は否定されない」。

第9回の $F$検定（aov：1元配置分散分析）

・多群の「母平均が等しいか」を分散比 $F = V_A / V_R$ で検定！
・群間分散 $V_A$ が誤差分散 $V_R$ より大きい側（右裾）だけを見る片側（上側）検定。
・$p < 0.05$ なら「群間の母平均に有意な差がある」！

理論整理

3群以上の検定フローチャートと前提条件の検定

正規性の検定（Shapiro-Wilk / KS）と、3群以上の等分散性の検定（Bartlett検定）

① 正規性の検定

・shapiro.test()（シャピロ・ウィルク検定）または lillie.test()（KS検定）。
・$H_0$：「正規分布に従う」
・全群で $p > 0.05$ なら正規性は否定されない

② 等分散性の検定（3群以上）

・bartlett.test(Y ~ X)（バートレット検定）。※2群の var.test の多群版。
・$H_0$：「各群の母分散は等しい」
・$p > 0.05$ なら等分散性は否定されない

③ 分散分析の選択

・正規＆等分散 $\rightarrow$ aov(Y ~ X)
・正規だが不等分散 $\rightarrow$ WelchのANOVA oneway.test(Y ~ X)（※最初からWelch法を使う流儀もある）
・非正規 $\rightarrow$ ノンパラメトリック（Kruskal-Wallis検定：第11回）

💻 Rの便利技：tapply(データ列, グループ列, 関数名)（例：tapply(niwatori$Taiju, niwatori$Esa, shapiro.test)）を使えば、6群すべての検定や平均・分散を1行で一括計算できます！
理論：多重比較 ①

多重比較の4大手法（どのペアに差があるかを特定する）

「総当たり比較（All-pairs）」の3手法と、「対照群との比較（Many-to-one）」のDunnett法
手法名 比較形式 特徴・推奨される場面 Rでの主な関数
1. Tukey-Kramer法
(Tukey's HSD検定)		 総当たり
($\binom{a}{2}$ ペア)		 総当たり比較の第一選択！ スチューデント化された範囲分布を用いて全ペアの最大差を補正。5群以上でも検出力が落ちにくい。 TukeyHSD(aov_obj)
glht(..., mcp(X="Tukey"))
2. Bonferroni法 総当たり
(任意ペア可)		 有意水準を比較総数 $m$ で割る（または $p$値を $m$ 倍する）。シンプルだが群数が増えて比較数 $m$ が多くなると保守的になり検出力が低下しやすい。 pairwise.t.test(..., p.adjust.method="bonferroni")
3. Holm法 総当たり
(段階的補正)		 Bonferroni法の改良版。$p$値が小さい順に「$\times m, \times (m-1), \dots$」と段階的に補正を緩めるため、FWERを5%以下に保ったまま常に Bonferroni法以上の検出力を持つ。 pairwise.t.test(..., p.adjust.method="holm")
4. Dunnett法 対照群 vs 他群
($a-1$ ペア)		 1つの対照区（Control / 無肥料など）と他の試験区だけを比較する（1対多）。比較回数が少ないため、対照区との差を検出しやすい。 glht(..., mcp(X="Dunnett"))
理論：多重比較 ②

Bonferroni vs Holm の仕組み ＆ アルファベット表記（CLD）

なぜHolm法はBonferroni法より検出力が高いのか？ そしてグラフ上の a, b, bc の読み方（＋発展コラム：FDR法）

Bonferroni法 vs Holm法（＋発展：FDR法）

  • Bonferroni法：全 $m=15$ ペアすべてで $p$値を一律に $\times 15$ 倍（上限1.0、FWER制御）。
  • Holm法：$p$値が小さい順（順位 $k=1\dots 15$）に $\times 15, \times 14, \dots$ 倍（$\times (m-k+1)$）と段階的に補正するため、常に $p_{\text{Holm}} \le p_{\text{Bonferroni}}$（$k=1$ で等号、$k \ge 2$ でより小さい $p$値）！
  • 💡 発展コラム（大規模解析のFDR / BH法）：遺伝子発現解析（RNA-seq）など数千〜数万項目を検定するときは、「有意と判定した中の偽陽性の割合（FDR）」を5%以下に抑える BH法（$\times \frac{m}{k}$ 倍、p.adjust.method="fdr"）を使う（※通常の3〜6群の実験ではTukey法やDunnett法を使う）。

Compact Letter Display (CLD: a, b, c) の鉄則

群数が増えると15ペアの表を見るのは大変！ そこで箱ひげ図の上に文字（a, b, c）を振ります：

  • 鉄則①：共通の文字が1つもない群間 ＝ 有意差あり（$p < 0.05$）！（例："a" と "b"、"a" と "bc"）
  • 鉄則②：同じ文字を1つでも共有する群間 ＝ 有意差なし！（例："a" と "ac" は a を共有するので差なし！）
CLD（アルファベット表記）の読み方：同じ文字を持っていれば「仲間（有意差なし）」！（課題3・発展4のニワトリ6群の例）

Wow体験 ② の数理

なぜ2群のとき「$t^2 = F$」が厳密に成り立つのか？

偶然ではない！ 1元配置分散分析が「2標本t検定の自然な3群以上への拡張」である証明
① 独立2群の Student $t$ 統計量を2乗すると
$$t^2 = \left(\frac{\bar{X}_1 - \bar{X}_2}{\sqrt{s_p^2\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}}\right)^2 = \frac{\dfrac{n_1 n_2}{n_1 + n_2}(\bar{X}_1 - \bar{X}_2)^2}{s_p^2}$$
② 2群（$a=2, df_A=1$）の ANOVA の $F$ 統計量
$$F = \frac{V_A}{V_R} = \frac{S_A / 1}{S_R / (n_1 + n_2 - 2)} = \frac{\dfrac{n_1 n_2}{n_1 + n_2}(\bar{X}_1 - \bar{X}_2)^2}{s_p^2}$$

発展課題5 (5) の考察のまとめ方

  • 2群（$a = 2$）のとき、ANOVAの群間平均平方 $V_A$（自由度 $df_A = 1$）は2群の平均差の2乗に比例し、群内誤差分散 $V_R$（自由度 $df_R = n_1 + n_2 - 2$）はStudentのt検定の合同分散（プール分散 $s_p^2$）と完全に一致する。
  • したがって代数的に $F = t^2$ が恒等的に成り立ち、自由度 $df$ の $t$分布の両側棄却域を2乗したものは自由度 $(1, df)$ の $F$分布の上側棄却域と一致するため、$p$値も100%同じ値になる（Welch法同士でも同様）。
  • すなわち、1元配置分散分析（1-way ANOVA）とは、独立2群のt検定（両側検定）を $a \ge 3$ 群へと一般化した手法そのものである！

トラブルシューティング（第9回でよくあるエラーと対処法）

RStudioでエラーが出たらここをチェック！

⚠️ there is no package called 'multcomp'

原因：多重比較パッケージ multcomp が未インストール。
対策：Consoleで install.packages("multcomp") を1回実行してから library(multcomp) を実行する。

⚠️ glht() で not a factor エラーが出る

原因：グループ列（Esa）が文字列（character）のままになっている。
対策：niwatori$Esa <- as.factor(niwatori$Esa) を実行して因子に変換してから aov() と glht() を実行する。

⚠️ plot(cld(...)) で上の a, b, c が切れる

原因：グラフ上部の余白（マージン）が足りない。
対策：plot() の直前に par(mar = c(5.1, 4.1, 6, 2.1)) を実行して上マージンを 6 に広げる。

⚠️ 大文字・小文字の違いによるエラー

対策：pairwise.t.test の引数は小文字で "bonferroni" / "holm"。一方、mcp(Esa = "Tukey") や "Dunnett" は先頭が大文字なので注意！

まとめ

本日のまとめと次回（第10回）への予告

1元配置分散分析と多重比較を制覇し、次回は「2つの要因と交互作用」へ！

本日の3大マスターポイント

1. 変動の分割と $F = t^2$：ANOVAは全体のばらつきを「群間分散（シグナル）」と「群内誤差分散（ノイズ）」に分割して検定し、2群のときは独立t検定と数学的に完全一致する。
2. 多重比較4手法の使い分け：通常の3〜6群比較では、総当たりの王道 Tukey-Kramer法、段階的補正の Holm法、対照群比較の Dunnett法（数千〜数万項目の大規模探索では FDR / BH法）。
3. Compact Letter Display (CLD)：共通文字がなければ有意差あり（$p < 0.05$）、同じ文字を共有すれば有意差なし！

次回（第10回）への予告：2元配置分散分析

本日は「肥料だけ」「飼料だけ」という1つの要因（1元配置）を比較しました。
では、「イネの遺伝子型（要因A）× 窒素肥料の量（要因B）」のように2つの要因を同時に組み合わせた実験ではどうなるでしょうか？
「品種Aには肥料が効くのに、品種Bには逆効果になる」といった相乗効果（交互作用 Interaction）を検定する第10回「2元配置分散分析（Two-way ANOVA）」をお楽しみに！
