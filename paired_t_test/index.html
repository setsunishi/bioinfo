🎧 統計的ノイズキャンセリングの威力

植物実験では、同じ品種でも「元々巨大な株（80g）」と「小ぶりな株（30g）」が混在します（個体差ノイズ）。 もし対応を無視して独立2群検定（Welch）を実行すると、個体差ノイズに邪魔されて $t=4.49, p=2 \times 10^{-5}$ にとどまります。

引き算（差）をとると…
株ごとの元々の大きさが完全に相殺され、純粋な時間変化（$-11.8$g）だけが浮き彫りに！
$\rightarrow$ $t=10.11, p=9 \times 10^{-14}$ へと、$p$値が約10億倍も明確に跳ね上がる！

📐 理論の階段（背理法から $t$分布・$p$値へ）

統計学の論理を一本の線でつなぐ

1. 背理法の思考

あえて「差はない（偶然だ）」という帰無仮説（$H_0$）を立て、そんな世界で手元のデータが出る確率（$p$値）を計算。確率が5%未満（$p < 0.05$）なら仮説を棄却して「差がある！」と結論づける。

2. なぜ「$t$分布」なのか？

母分散 $\sigma^2$ は未知のため、標本標準偏差 $s$ で代用する。分母の $s$ も実験ごとにブレるため、正規分布（$Z$）よりも裾野が広い$t$分布（自由度 $df = n-1$）に従う。

3. $p$値の幾何学的直感

自由度 $df$ の $t$分布の山を描き、計算した $t$値 より外側の「裾野の面積（確率）」こそが $p$値。$t$値が山の中心から離れるほど面積（$p$値）は極小になり有意と判定される。

⚠️ 'table1.xlsx' does not exist エラー

作業ディレクトリ（Working Directory）が Excel ファイルの置き場所と一致していません。
RStudio メニューの Session $\rightarrow$ Set Working Directory $\rightarrow$ Choose Directory... で、ダウンロードした table1.xlsx があるフォルダを選択してください。

⚠️ 片側検定で p値が 0.999... になった

対立仮説の向き（greater / less）が逆になっています。R は第1引数から第2引数を引く（x - y）ため、t.test(SW5, SW35, ...) で「35日目に減少した（SW5 > SW35）」を検定する場合は alternative = "greater" を指定します。
