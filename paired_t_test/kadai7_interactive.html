統計学的仮説検定 ① 〜1標本t検定と対応のあるt検定〜 | イネ登熟期茎葉重解析

客観テスト得点: 0 / 100 点

📖 演習の背景と本日のゴール

背景知識

イネ76系統の分離集団において、出穂後の茎葉重（穂以外の地上部乾物重）を測定しました。
出穂後、栄養を穂に送って茎葉が枯れる「枯れ上がる系統（Senescence）」と、緑と重さを保ち続ける「枯れ上がりにくい系統（Stay-green）」が存在します。

データセット（クリックでダウンロード）：
・table1.xlsx: Genotype = A（24系統, ジャポニカ型アレル）
・table2.xlsx: Genotype = B（52系統, インディカ型アレル）
・SW5: 出穂後5日重 (g/個体)　／　SW35: 出穂後35日重 (g/個体)

課題1：Genotype A の両側検定（Table 1, 24系統）

基本検定（20点）

RStudioで以下のコードを実行し、出力された数値を入力してください。

library(readxl) table1 <- read_excel("table1.xlsx") t.test(table1$SW5, table1$SW35, paired = TRUE, alternative = "two.sided")

課題2：Genotype B の両側検定（Table 2, 52系統）

基本検定（20点）

RStudioで以下のコードを実行し、数値を入力してください。

table2 <- read_excel("table2.xlsx") t.test(table2$SW5, table2$SW35, paired = TRUE, alternative = "two.sided")

課題3：Genotype B の片側検定（SW35 < SW5）

基本検定（20点）

「出穂後35日の茎葉重が5日よりも小さい（減少している）」ことを片側検定で検証します。

# SW5 - SW35 が正（>0）であることを検証 t.test(table2$SW5, table2$SW35, paired = TRUE, alternative = "greater")

発展課題5【Wow②：要約統計量の罠と逆走個体の探偵団】

探究課題（20点）
問い： Table 2 の52系統は全員枯れ上がった（減少した）のでしょうか？
変化量（diff <- table2$SW35 - table2$SW5）を計算し、全体が激減する中で「逆走して増加した（差がプラス）3系統の行番号」を突き止めてください！
# 逆走した系統（差がプラス）を抽出するRコード diff_B <- table2$SW35 - table2$SW5 which(diff_B > 0)
