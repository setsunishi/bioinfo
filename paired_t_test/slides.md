# 【理論】統計学的推測とは？（母集団と標本）

### 私たちが知りたいのは「母集団」、手に入るのは「標本」

- **母集団（Population）**
  - 知りたい対象の全体（例：あるイネ品種のすべての個体の茎葉重）
  - 母平均 $\mu$ や 母分散 $\sigma^2$ は通常**「神のみぞ知る未知の値」**
- **標本（Sample）**
  - 実験で実際に測定できた一部の個体（例：育てた24個体や52個体）
  - 標本平均 $\bar{x}$ や 不偏分散 $s^2$ は手元で計算できる
- **実験科学のジレンマ**
  - 標本から計算した平均値には、必ず**サンプリングの偶然（実験誤差）**が含まれる！
  - 「平均値が違う」からといって、本当に「母集団に差がある」と言い切れるだろうか？

# 【理論】中心極限定理と標準誤差（SE）

### 標本サイズ $n$ を増やすと、標本平均のブレは急激に縮まる

::: columns
::: {.column width="50%"}
### 標本平均のばらつき（標準誤差）
$$SE = \frac{s}{\sqrt{n}}$$
- $s$: 標本の標準偏差（個体ごとのばらつき）
- $n$: サンプルサイズ（個体数）
- **ポイント**：個体数 $n$ を4倍に増やせば、平均値の推定誤差（SE）は $\frac{1}{2}$ に減る！
:::
::: {.column width="50%"}
### 中心極限定理の直感
- もとの分布がどんな形であっても、多数の標本からとった「平均値」の分布は、きれいな**正規分布**に近づく。
- 「誤差の平均値は正規分布に従う」
  $\rightarrow$ これが統計的検定を支える最大の数学的根拠！
:::
:::

# 【理論】仮説検定の思考法：背理法のアプローチ

### 「差がある！」と直接証明するのは難しい。なぜなら「偶然かも」と言い逃れできるから。

- **科学者のアプローチ（背理法）**
  1. あえて**「差はない（効果ゼロ、偶然の偏りにすぎない）」**という仮説を立てる（**帰無仮説**）
  2. もし「差がない世界」だとしたら、手元のデータのような結果が偶然生じる確率はどれくらいかを計算する（**$p$値**）
  3. その確率があまりにも低ければ（例: 5%未満）…
  4. $\rightarrow$ **「差がないという最初の仮定に無理があった！」**と判断して棄却する
  5. 晴れて**「差がある（対立仮説）」**と科学的に主張できる！

# 【理論】帰無仮説（H₀）と対立仮説（H₁）

### 検定を始める前に、必ず言葉と数式で仮説を定義する

- **帰無仮説（Null Hypothesis: $H_0$）**
  - 「無に帰したい（否定したい）」仮説
  - 「差はない」「効果はない」「変化量はゼロである」
  - 数式例: $\mu_d = 0$ （差の母平均は0）
- **対立仮説（Alternative Hypothesis: $H_1$）**
  - 主張したい本命の仮説
  - 「差がある」「効果がある」「変化している」
  - 数式例: $\mu_d \neq 0$ （両側） または $\mu_d > 0$ （片側）

# 【理論】標準化とZ値（理想の世界：母分散が既知の場合）

### 観測されたズレを「偶然の誤差（標準誤差）」で割って標準化する

$$Z = \frac{\bar{x} - \mu_0}{\frac{\sigma}{\sqrt{n}}} = \frac{\text{標本平均と基準値の差}}{\text{母標準誤差 (SE)}} \sim N(0, 1)$$

::: columns
::: {.column width="50%"}
### 標準正規分布 $N(0, 1)$ の性質
- 平均 $0$、分散 $1$ の左右対称な釣鐘型の山
- **95% のデータは $[-1.96, +1.96]$ の間に収まる**
- $Z > 1.96$ または $Z < -1.96$ の値が出る確率はわずか **5% 未満**
:::
::: {.column width="50%"}
### もし母分散 $\sigma^2$ を知っているなら…
- $Z$ を計算し、$\pm 1.96$ より外側に出れば「偶然の誤差とは考えにくい（有意差あり）」と即座に判定できる！（これが **$Z$検定**）
- **しかし、ここに実験科学の大きな壁が立ちはだかる…**
:::
:::

# 【理論】Z値からt値へ：なぜ「t分布」が必要なのか？

### 実験科学の冷酷な現実：母分散 $\sigma^2$ なんて誰も知らない！

::: columns
::: {.column width="50%"}
### 母標準偏差 $\sigma$ を標本 $s$ で代用する
$$t = \frac{\bar{x} - \mu_0}{\frac{s}{\sqrt{n}}}$$
- 母分散 $\sigma^2$ は「神のみぞ知る未知の値」
- そこで、手元の標本から計算した**標本標準偏差 $s$** を代わりに使う！
- これが **$t$値（$t$統計量）**！
:::
::: {.column width="50%"}
### なぜ正規分布（Z）からズレるのか？
- 分子の標本平均 $\bar{x}$ だけでなく、**分母の $s$ も標本ごとにランダムにブレる！**
- 分母の不確実性の分だけ、正規分布よりも**「裾野が広く（外れ値が出やすく）、頂点が低い山」**になる
- ギネスビールの醸造技師 Gosset（ペンネーム: Student）が導いた **「$t$分布」** に従う！
:::
:::

# 【理論】t分布の形を決める「自由度（df）」

### サンプルサイズ $n$ が小さいほど、t分布の裾野は重く広がる

::: columns
::: {.column width="50%"}
### 自由度（Degrees of Freedom: $df$）
$$df = n - 1$$
- 標本のばらつき $s^2$ を計算するときに、標本平均 $\bar{x}$ という「1つの拘束条件」を使うため、自由に動けるデータの数は $n - 1$ 個になる
- $t$分布の形を決める唯一のパラメータ！
:::
::: {.column width="50%"}
### 自由度による95%境界の変化
- **$n = 5$ ($df = 4$)**: 95%境界は **$\pm 2.776$**（裾が非常に広い）
- **$n = 10$ ($df = 9$)**: 95%境界は **$\pm 2.262$**
- **$n = 25$ ($df = 24$)**: 95%境界は **$\pm 2.064$**
- **$n \to \infty$**: 正規分布の **$\pm 1.960$** にピタリと一致！
:::
:::

> **💡 だから R の出力に必ず自由度が表示される！**
> `t.test()` の結果に `df = 23`（$n=24$）や `df = 51`（$n=52$）と出るのは、**「どの形の $t$分布を使って確率を計算したか」**を表しているのです！

# 【理論】t分布からp値へ（p値の正しい幾何学的定義）

### $p$値とは「$t$分布の曲線の裾野の面積（確率）」である！

::: columns
::: {.column width="50%"}
### $t$値から $p$値 を求めるメカニズム
1. 帰無仮説 $H_0$（差はない）を仮定し、自由度 $df$ の $t$分布の山を描く
2. 手元のデータから計算した $t$値 を横軸にプロットする
3. **その $t$値 より外側の「裾野の面積（積分値）」**を計算する
4. $\rightarrow$ **この面積こそが $p$値（確率）！**
:::
::: {.column width="50%"}
### $t$値 と $p$値 の関係
- **$t$値 が小さい（山の中央付近）**:
  - 裾野の面積が広い $\rightarrow$ **$p$値が大きい（$p > 0.05$）** $\rightarrow$ 偶然の範囲内
- **$t$値 が大きい（山の裾野の遠く）**:
  - 裾野の面積が極小 $\rightarrow$ **$p$値が極小（$p < 0.05$）** $\rightarrow$ 偶然とは言えない珍事！
:::
:::

# 【理論】p値の正しい解釈（最重要！）

### $p$値とは「帰無仮説が正しいとしたとき、手元のデータ以上に極端な結果が得られる確率」

- **よくある誤解 ❌**:
  - 「帰無仮説が正しい確率」（間違い！）
  - 「対立仮説が正しい確率」（間違い！）
  - 「実験が成功した確率」（間違い！）
- **正しい理解 ⭕**:
  - **「差がない世界（$H_0$）」という仮定のもとでのシミュレーション確率**
  - $p = 0.03$ $\rightarrow$ 「もし本当は差がないとしたら、偶然こんな極端なデータが出る確率はたったの 3% しかない」
  - だから、「差がないという仮定を捨てて、差があると結論づけよう！」となる。

# 【理論】有意水準（α）と棄却域

### どこまで確率が低ければ「偶然ではない」と認めるか？

- **有意水準（Significance level: $\alpha$）**
  - 科学界の慣例として、通常 **$\alpha = 0.05$ (5%)** または **$0.01$ (1%)** を設定
  - 実験を始める前にあらかじめ決めておくルール
- **判定基準**:
  - **$p < \alpha$（例: $p < 0.05$）**
    - $\rightarrow$ 帰無仮説を**棄却（Reject）**
    - 「統計学的に有意な差がある（Statistically significant）」
  - **$p \ge \alpha$（例: $p \ge 0.05$）**
    - $\rightarrow$ 帰無仮説を**採択（保留・棄却されない: Fail to reject）**
    - 「有意な差があるとはいえない（差がないとは証明していない）」

# 【理論】対応のあるt検定の数学的本質

### 「引き算（差）」をとれば、2群の問題が1標本問題にワープする！

::: columns
::: {.column width="50%"}
- 各個体 $i$ について、**差 $d_i$** を計算する：
  $$d_i = x_{i, \text{後}} - x_{i, \text{前}}$$
- すると、データは「$n$個の差の値 $d_1, d_2, \dots, d_n$」という**1列のデータ**になる！
- **仮説の言い換え**:
  - $H_0$: 差の母平均 $\mu_d = 0$
  - $H_1$: 差の母平均 $\mu_d \neq 0$
:::
::: {.column width="50%"}
### 検定統計量 $t$ の計算式
$$t = \frac{\bar{d} - 0}{\frac{s_d}{\sqrt{n}}}$$
- $\bar{d}$: 差の標本平均
- $s_d$: 差の標準偏差
- $n$: ペアの数（個体数）
- 自由度: $df = n - 1$
- **完全に「基準値0に対する1標本t検定」と同じ！**
:::
:::

# 【Wow①】対応のある検定の真の威力：ノイズキャンセリング

### なぜ対応をとるのか？ $\rightarrow$ 「個体差ノイズ」を消し去るため！

- **実験科学の悩み：個体差がデカすぎる**
  - 植物実験では、同じ品種でも「元々太くて大きい株」と「小ぶりな株」がいる（個体差ノイズ）。
  - 普通に2群を並べて比較すると、個体差ノイズに邪魔されて、せっかくの薬効や時間変化が見えなくなる。
- **引き算（差）のマジック**
  - 大きい株：$80\text{g} \rightarrow 68\text{g}$ （差: $-12\text{g}$）
  - 中くらいの株：$50\text{g} \rightarrow 38\text{g}$ （差: $-12\text{g}$）
  - 小さい株：$30\text{g} \rightarrow 18\text{g}$ （差: $-12\text{g}$）
- $\rightarrow$ **引き算した瞬間、株ごとの「元々の大きさ」が相殺されて消える！**
- 純粋な「時間変化のシグナル（$-12\text{g}$）」だけが残り、検出力が爆発的に跳ね上がる！

# 【Wow①実演】同じデータで対応を無視したらどうなるか？

### Table 2（52系統）で実際に比較してみると…衝撃の結果！

::: columns
::: {.column width="50%"}
### あえて対応を無視（Welch検定）
```r
t.test(SW5, SW35, paired = FALSE)
```
- $t = 4.49$
- $df = 97.35$
- **$p = 1.98 \times 10^{-5}$**（約 0.00002）
- 個体差のばらつきが分母に入り、$t$値が小さくなる
:::
::: {.column width="50%"}
### 正しく対応を考慮（Paired検定）
```r
t.test(SW5, SW35, paired = TRUE)
```
- **$t = 10.11$**（2倍以上！）
- $df = 51$
- **$p = 8.99 \times 10^{-14}$**
- 個体差ノイズが消滅し、**$p$値が約10億倍も明確に！**
:::
:::

> **持ち帰る教訓**：同じ個体を追跡できる実験系では、対応のある検定を使うことで、少ないサンプル数で圧倒的に強力なシグナルを検出できる！

# 【理論】両側検定 vs 片側検定

### 検定をかける前に、対立仮説の方向性を決めておく

::: columns
::: {.column width="50%"}
### 両側検定（Two-sided）
- **対立仮説**: $\mu_1 \neq \mu_2$（差がある）
- 増えるか減るか、事前にわからない・どちらでも興味がある場合
- 棄却域は両端に 2.5% ずつ（計 5%）
- **迷ったら両側検定が科学の基本！**
:::
::: {.column width="50%"}
### 片側検定（One-sided）
- **対立仮説**: $\mu_1 > \mu_2$ または $\mu_1 < \mu_2$
- 構造上、一方にしか変化しないことが明らかな場合（例: 枯れる方向しかあり得ない）
- 棄却域は片端に 5% まとめて置く
- **注意**: データを見てから片側にするのはズル（p-hacking）！
:::
:::

# 【超重要】Rでの片側検定の向き（迷子防止ルール）

### `alternative="greater"` なのか `"less"` なのか？

```r
t.test(x, y, paired = TRUE, alternative = "???")
```

- **Rの内部の引き算**: 第1引数から第2引数を引く $\rightarrow$ **`x - y`**
- **ルールの覚え方**:
  - **対立仮説が `x > y`（差がプラス）を主張したいとき**
    $\rightarrow$ **`alternative = "greater"`**
  - **対立仮説が `x < y`（差がマイナス）を主張したいとき**
    $\rightarrow$ **`alternative = "less"`**

::: columns
::: {.column width="50%"}
```r
# パターン1: SW5 > SW35 を検証
t.test(table2$SW5, table2$SW35,
       paired = TRUE,
       alternative = "greater")
```
:::
::: {.column width="50%"}
```r
# パターン2: SW35 < SW5 を検証
t.test(table2$SW35, table2$SW5,
       paired = TRUE,
       alternative = "less")
```
:::
:::
$\rightarrow$ **どちらも全く同じ結果（$p = 4.493 \times 10^{-14}$）になります！**
