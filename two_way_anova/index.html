🌟 本回の2つの「発見（Wow!）」体験

交互作用の逆転現象と、多群の統計的ノイズキャンセリングを体感する
【発見体験 ①】

⚡ 1要因ずつ見ても差がないのに、組み合わせると差が出る！「クロスオーバー交互作用」

フライドチキンの試作データ（kadai3.tsv：味「普通／辛口」× 衣「普通／クリスピー」）を1要因ずつ別々に集計すると、味の主効果も（$p = 0.086$）、衣の主効果も（$p = 0.364$）有意になりません。

なぜ主効果が消えて交互作用（$p = 0.0125$）だけが有意になるのか？
・実は「普通味には普通の衣（74.3点）」「辛口にはクリスピー（79.7点）」が高評価で、逆のミスマッチ（普通味×クリスピー 71.0点、辛口×普通の衣 72.7点）が低評価になっています！
・このように効果の向きが逆転（折れ線がX字に交差）していると、片方の要因だけで平均したときにプラスとマイナスが打ち消し合ってしまいます。2元配置分散分析で初めて「組み合わせの妙」を検出できます！
【発見体験 ②】

🎧 第7回「ノイズキャンセリング」の多群版！ 反復測定ANOVAによる個人差の分離

もし上記のフライドチキン4種のスコアが、別々の60人ではなく「同じ15人のパネリスト（Panel: A〜O）が4種類すべてを食べ比べたデータ（kadai3_2.tsv）」だったらどうなるでしょうか？

aov(Score ~ AjiKoromo + Panel) で個人差を引き算すると…
・評価者ごとの「採点の甘さ・辛さの個人差（$S_{\text{Panel}} = 2035.8$）」が残差から分離されることで、誤差分散 $V_R$ が $60.18 \to \mathbf{31.77}$ へと約半分に減少！
・その結果、対応なし（発展4）では $p = 0.0759$ で惜しくも有意にならなかった「辛口クリスピー vs 辛口普通の衣」が $p = 0.00785$（1%水準有意！）へと明確に検出されます！

📐 理論の3本柱（主効果と交互作用・多重比較の分岐・反復測定）

2要因実験を正しく解析するための統計ロジック

1. 平方和の4分割と交互作用

繰り返しがある2元配置（aov(Y ~ A * B)）では、全体のばらつき $S_T$ を「要因Aの主効果 $S_A$」「要因Bの主効果 $S_B$」「交互作用 $S_{A \times B}$」「残差誤差 $S_R$」の4つに分割し、それぞれを残差分散 $V_R$ で割った $F$値で検定します。

2. 交互作用の有無による多重比較の分岐

・交互作用が非有意（$p \ge 0.05$）：要因同士は独立に効いているため、有意な主効果ごとに水準間で多重比較を行う（課題3）。
・交互作用が有意（$p < 0.05$）：組み合わせで効き方が変わるため、paste(A, B, sep="") で全 $a \times b$ 試験区を1次元に展開して多重比較を行う（課題2・発展4）。

3. 繰り返しなし・反復測定は + を使う

・1つの条件組み合わせにデータが1つしかない場合（練習3）や、同一被験者・パネリストが全条件を測定した反復測定（練習4・発展5）では、aov(Y ~ A + B)（プラス記号）を使って第2要因（温度や個人差）の変動を分離します。

課題1 & 課題2: 作物収量データ（kadai1.tsv）の2元配置分散分析と8試験区展開の多重比較

# タブ区切りファイル (.tsv) は read.delim() で読み込む kadai1 <- read.delim("kadai1.tsv", stringsAsFactors = TRUE) summary(kadai1) # 【課題1】繰り返しありの2元配置分散分析（Soil * Fertilizer） summary(aov(Yield ~ Soil * Fertilizer, data = kadai1)) # 【課題2】交互作用が有意(p = 0.0229)なので、8試験区 (SoilFert) に展開して多重比較 kadai1$SoilFert <- as.factor(paste(kadai1$Soil, kadai1$Fertilizer, sep = "")) summary(kadai1) library(multcomp) result1 <- aov(Yield ~ SoilFert, data = kadai1) summary(result1) result2 <- glht(result1, linfct = mcp(SoilFert = "Tukey")) summary(result2) cld(result2) par(mar = c(5.1, 4.1, 6, 2.1)) plot(cld(result2))

課題3: ミネラルウォーター評定データ（kadai2.tsv：交互作用なし）の2-way ANOVAと主効果の多重比較

# 日本語を含むTSVファイルなので fileEncoding = "utf8" を指定 kadai2 <- read.delim("kadai2.tsv", stringsAsFactors = TRUE, fileEncoding = "utf8") summary(kadai2) # (1) 繰り返しありの2元配置分散分析（Ondo * Meigara） summary(aov(Score ~ Ondo * Meigara, data = kadai2)) # (2) 交互作用が非有意(p = 0.115)なので、主効果（Ondo と Meigara）ごとに多重比較 library(multcomp) # 温度 (Ondo) の比較 res_ondo <- aov(Score ~ Ondo, data = kadai2) summary(res_ondo) tukey_ondo <- glht(res_ondo, linfct = mcp(Ondo = "Tukey")) summary(tukey_ondo) cld(tukey_ondo) # 銘柄 (Meigara) の多重比較 res_meigara <- aov(Score ~ Meigara, data = kadai2) summary(res_meigara) tukey_meigara <- glht(res_meigara, linfct = mcp(Meigara = "Tukey")) summary(tukey_meigara) cld(tukey_meigara) par(mar = c(5.1, 4.1, 6, 2.1)) # par(family = "HiraKakuProN-W6") # Macでグラフの日本語が文字化けする場合のみ実行 plot(cld(tukey_meigara))

発展課題4: フライドチキン試食データ（kadai3.tsv：独立60人）のクロスオーバー交互作用と4群展開

kadai3 <- read.delim("kadai3.tsv", stringsAsFactors = TRUE, fileEncoding = "utf8") summary(kadai3) # (1) 繰り返しありの2元配置分散分析（主効果は非有意だが交互作用 Aji:Koromo が p = 0.0125 で有意！） summary(aov(Score ~ Aji * Koromo, data = kadai3)) # (2) 4試験区 (AjiKoromo) に展開してTukey-Kramer多重比較 kadai3$AjiKoromo <- as.factor(paste(kadai3$Aji, kadai3$Koromo, sep = "")) library(multcomp) res1_k3 <- aov(Score ~ AjiKoromo, data = kadai3) summary(res1_k3) res2_k3 <- glht(res1_k3, linfct = mcp(AjiKoromo = "Tukey")) summary(res2_k3) cld(res2_k3) par(mar = c(5.1, 4.1, 6, 2.1)) plot(cld(res2_k3))

発展課題5: 同一パネリスト15名の反復測定データ（kadai3_2.tsv）による個人差（Panel）の分離

kadai3_2 <- read.delim("kadai3_2.tsv", stringsAsFactors = TRUE, fileEncoding = "utf8") summary(kadai3_2) # (1) パネリストの個人差 (Panel) を分離する反復測定ANOVA（+ Panel を付ける！） res1_k3_2 <- aov(Score ~ AjiKoromo + Panel, data = kadai3_2) summary(res1_k3_2) # (2) 個人差を除去したモデルでのTukey-Kramer多重比較とCLD（発展4とp値・CLDを比較！） library(multcomp) res2_k3_2 <- glht(res1_k3_2, linfct = mcp(AjiKoromo = "Tukey")) summary(res2_k3_2) cld(res2_k3_2) par(mar = c(5.1, 4.1, 6, 2.1)) plot(cld(res2_k3_2))
