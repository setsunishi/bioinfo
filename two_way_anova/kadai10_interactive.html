統計学的仮説検定 ④ 〜2元配置分散分析（Two-way ANOVA）と交互作用・反復測定ANOVA〜

客観テスト得点: 0 / 100 点

📖 本日の提出課題の範囲・提出方法とデータセット

必読ガイド

本日は、2つの要因（例：土壌×肥料、温度×銘柄、味×衣）が結果に与える主効果（Main Effect）と交互作用（Interaction）を検定する2元配置分散分析（Two-way ANOVA）、および交互作用の有無に応じた多重比較を行います。
さらに、同一パネリスト15名が4種類の試作品を食べ比べた反復測定データを用いて、評価者の個人差（Panel）を分離することによる検出力の向上を検証します。

📥 課題用データセット（クリックでダウンロードし、RStudioの作業ディレクトリに配置してください）：
・kadai1.tsv: 土壌2種（SoilA, SoilB）× 肥料4段階（N100〜N400）の作物収量データ（課題1・課題2で使用）
・kadai2.tsv: 温度2種（冷蔵庫, 常温）× 銘柄3種（イカアン, ビビッテル, ボスビック）の水おいしさ評定データ（課題3で使用）
・kadai3.tsv: フライドチキンの味2種 × 衣2種（独立な60人が試食：発展課題4で使用）
・kadai3_2.tsv: フライドチキン4種 × 同一パネリスト15名（反復測定：発展課題5で使用）
・提出方法：以下の課題1〜3・発展課題4〜5（各20点×5＝100点満点）および総合考察を入力し、最下部の「📥 提出用レポートHTMLを書き出す」ボタンでダウンロードされたHTMLファイルを提出してください。

課題1：作物収量データの2元配置分散分析（土壌2種 × 肥料4段階）

基本検定（20点）

RStudioで kadai1.tsv を読み込み、繰り返しありの2元配置分散分析（summary(aov(Yield ~ Soil * Fertilizer, data = kadai1))）を実行して、土壌・肥料の主効果と交互作用（Soil:Fertilizer）の統計量を入力してください。

kadai1 <- read.delim("kadai1.tsv", stringsAsFactors = TRUE) summary(kadai1) # 繰り返しありの2元配置分散分析（アスタリスク * で主効果と交互作用を同時検定） summary(aov(Yield ~ Soil * Fertilizer, data = kadai1))

課題2：交互作用が有意な場合の8試験区展開とTukey-Kramer多重比較

多重比較（20点）

課題1で交互作用が有意となったため、Soil と Fertilizer を連結した8試験区（SoilFert）を作成し、Tukey-Kramer多重比較と cld() によるアルファベット表記を行ってください。

# SoilとFertilizerをつなげて8試験区の因子 SoilFert を作成 kadai1$SoilFert <- as.factor(paste(kadai1$Soil, kadai1$Fertilizer, sep = "")) summary(kadai1) library(multcomp) result1 <- aov(Yield ~ SoilFert, data = kadai1) summary(result1) result2 <- glht(result1, linfct = mcp(SoilFert = "Tukey")) summary(result2) cld(result2) par(mar = c(5.1, 4.1, 6, 2.1)) plot(cld(result2))

課題3：ミネラルウォーターのおいしさ評定（交互作用がない2-way ANOVA）

主効果比較（20点）

kadai2.tsv（温度 Ondo：冷蔵庫／常温 × 銘柄 Meigara：イカアン／ビビッテル／ボスビック）に対して2元配置分散分析を行い、交互作用が非有意であることを確認した上で、主効果ごとの多重比較を行ってください。

kadai2 <- read.delim("kadai2.tsv", stringsAsFactors = TRUE, fileEncoding = "utf8") summary(kadai2) # (1) 繰り返しありの2元配置分散分析 summary(aov(Score ~ Ondo * Meigara, data = kadai2)) # (2) 交互作用が非有意(p = 0.115)なので、主効果（Ondo と Meigara）ごとに多重比較 library(multcomp) res_ondo <- aov(Score ~ Ondo, data = kadai2) cld(glht(res_ondo, linfct = mcp(Ondo = "Tukey"))) res_meigara <- aov(Score ~ Meigara, data = kadai2) tukey_meigara <- glht(res_meigara, linfct = mcp(Meigara = "Tukey")) summary(tukey_meigara) cld(tukey_meigara) par(mar = c(5.1, 4.1, 6, 2.1)) plot(cld(tukey_meigara))

発展課題4【Wow①：主効果が消える？！ クロスオーバー交互作用（kadai3.tsv）】

探究課題（20点）
問い： 4種類のフライドチキン試作品（味 Aji：普通味／辛口 × 衣 Koromo：普通の衣／クリスピー）を独立な60人（各15人）に試食してもらった kadai3.tsv について、2元配置分散分析（Score ~ Aji * Koromo）と4群展開（AjiKoromo）の多重比較を行ってください。
kadai3 <- read.delim("kadai3.tsv", stringsAsFactors = TRUE, fileEncoding = "utf8") summary(kadai3) # (1) 繰り返しありの2元配置分散分析（主効果 Aji, Koromo と 交互作用 Aji:Koromo の p値に注目！） summary(aov(Score ~ Aji * Koromo, data = kadai3)) # (2) 交互作用が有意なので4試験区 (AjiKoromo) に展開してTukey多重比較 kadai3$AjiKoromo <- as.factor(paste(kadai3$Aji, kadai3$Koromo, sep = "")) library(multcomp) res1_k3 <- aov(Score ~ AjiKoromo, data = kadai3) summary(res1_k3) res2_k3 <- glht(res1_k3, linfct = mcp(AjiKoromo = "Tukey")) summary(res2_k3) cld(res2_k3)

発展課題5【Wow②：同一パネリスト15名の反復測定ANOVAによる個人差の分離（kadai3_2.tsv）】

探究課題（20点）
問い： もし4種類のフライドチキンを別々の60人ではなく「同一の15人のパネリスト（Panel: A〜O）が4種類すべてを試食・採点したデータ（kadai3_2.tsv）」であった場合、評価者の個人差を分離する反復測定分散分析 aov(Score ~ AjiKoromo + Panel, data = kadai3_2) と多重比較を実行し、発展課題4（対応なし）から残差分散や $p$値・CLDがどう変化するか検証してください。
kadai3_2 <- read.delim("kadai3_2.tsv", stringsAsFactors = TRUE, fileEncoding = "utf8") summary(kadai3_2) # (1) 評価者の個人差 (Panel) をモデルに入れて分離する反復測定ANOVA res1_k3_2 <- aov(Score ~ AjiKoromo + Panel, data = kadai3_2) summary(res1_k3_2) # (2) 個人差を分離したモデルでのTukey-Kramer多重比較とCLD library(multcomp) res2_k3_2 <- glht(res1_k3_2, linfct = mcp(AjiKoromo = "Tukey")) summary(res2_k3_2) cld(res2_k3_2)

総合考察：2元配置分散分析における「交互作用」と「ブロック（対応）要因」の意義
