理論の核心 ①

なぜ「2元配置分散分析（Two-way ANOVA）」なのか？

2つの要因（要因A × 要因B）の「主効果（Main Effect）」と「交互作用（Interaction）」を同時に検定する

① 主効果（Main Effects）＝ 各要因単独の効果

  • 要因Aの主効果：要因Bの違いを平均（無視）したときに、要因Aの水準間で平均値に差があるか。
  • 要因Bの主効果：要因Aの違いを平均（無視）したときに、要因Bの水準間で平均値に差があるか。
  • 交互作用がない場合、全体の効果は「要因Aの効果 ＋ 要因Bの効果」という単純な足し算（加法モデル）で表せる。

② 交互作用（Interaction：$A \times B$）＝ 相乗・相殺効果

  • 定義：「一方の要因の水準によって、もう一方の要因の効果（効き方）が変わること」。
  • 相乗効果（Synergy）：土壌Aでは肥料を増やしても少ししか伸びないが、土壌Bでは肥料を増やすと収量が急増する（課題1）。
  • 相殺・逆転効果（Crossover）：普通味には普通の衣、辛口にはクリスピーが合い、逆の組み合わせだと評価が下がる（発展4）。
💡 1要因ずつ別々に実験（1元配置ANOVA×2回）してしまうと、この「要因Aと要因Bの組み合わせによって生じる交互作用」を永久に見落としてしまいます！
理論の核心 ②

視覚で一発理解！ 交互作用プロット（折れ線グラフ）の3パターン

「折れ線が平行なら交互作用なし」「非平行（扇状）や交差（X字）なら交互作用あり！」

① 交互作用なし（平行）

・2本の折れ線が平行（どの水準でも上昇幅が同じ）。
・練習1・課題3がこの型！ 主効果ごとに多重比較すればOK。

② 相乗的交互作用（非平行）

・折れ線の傾きが大きく異なる（片方の条件で効果が急拡大）。
・練習2・課題1・2がこの型！ 全試験区を展開して多重比較する。

③ 逆転交互作用（X字交差）

・折れ線が「×字」に交差！
・左右を平均すると高低が打ち消し合い、主効果が非有意（差なし）に見えてしまう（発展4）。

理論：変動の分割 ①

変動（平方和）と自由度の分割（① 繰り返しありの場合）

総平方和 $S_T$ ＝ 要因A平方和 $S_A$ ＋ 要因B平方和 $S_B$ ＋ 交互作用平方和 $S_{A \times B}$ ＋ 残差平方和 $S_R$
総変動（総平方和 $S_T$） ｜ 総自由度 $df_T = N - 1$
全データ $N = a \times b \times r$ 個の全体平均 $\bar{X}$ からのズレの2乗和
① 要因Aの主効果 ($S_A$)
自由度 $df_A = a - 1$
$V_A = \dfrac{S_A}{a - 1}$
$F_A = V_A / V_R$
② 要因Bの主効果 ($S_B$)
自由度 $df_B = b - 1$
$V_B = \dfrac{S_B}{b - 1}$
$F_B = V_B / V_R$
③ 交互作用 ($S_{A \times B}$)
$df_{A \times B} = (a-1)(b-1)$
$V_{A \times B} = \dfrac{S_{A \times B}}{(a-1)(b-1)}$
$F_{A \times B} = V_{A \times B} / V_R$
④ 残差誤差 ($S_R$)
$df_R = N - ab$
$V_R = \dfrac{S_R}{N - ab}$
【全 $F$検定の分母】
R出力の行名 自由度 Df 平方和 Sum Sq 平均平方 Mean Sq 分散比 F value 帰無仮説 $H_0$ と判定
要因A（例: Soil） $a - 1$ $S_A$ $V_A = S_A / (a-1)$ $F_A = V_A / V_R$ $H_0$: 要因Aの主効果なし（$p < 0.05$ で効果あり）
要因B（例: Fertilizer） $b - 1$ $S_B$ $V_B = S_B / (b-1)$ $F_B = V_B / V_R$ $H_0$: 要因Bの主効果なし（$p < 0.05$ で効果あり）
交互作用 A:B $(a-1)(b-1)$ $S_{A \times B}$ $V_{A \times B} = S_{A \times B} / df_{A \times B}$ $F_{A \times B} = V_{A \times B} / V_R$ $H_0$: 交互作用なし（$p < 0.05$ で相乗・相殺効果あり！）
残差 Residuals $N - ab$ $S_R$ $V_R = S_R / (N - ab)$ — 各試験区内の個体差（純粋な誤差ノイズ）
理論：変動の分割 ②

繰り返しなし ＆ 対応のある反復測定（Y ~ A + B）の仕組み

第2要因（温度や評価者の個人差）を変動から引き算することで、残差誤差 $V_E$ を小さくする！

なぜ Y ~ A + B では交互作用を検定しないのか？

  • 1つのマス（条件A×条件B）にデータが1個しかないとき、総データ数は $N = ab$ 個。
  • もし交互作用まで入れようとすると、残差自由度 $df_R = N - ab = 0$ となり、分母の誤差分散が計算できない。
  • そこで「交互作用はない」と仮定し、自由度 $(a-1)(b-1)$ の残りの変動を誤差変動 $S_E$（`Residuals`）として $F$検定の分母に使う！

対応のある多群比較（反復測定）での絶大なメリット

  • 同じ15人のパネリスト（Panel）が4種類のチキン（AjiKoromo）を採点したとき、人によって「甘め・辛め」の個人差がある。
  • 1元配置 aov(Score ~ AjiKoromo) では個人差がすべて残差 $S_R$ に混ざり、分母 $V_R$ が膨らんで検出力が落ちる。
  • aov(Score ~ AjiKoromo + Panel) とすると、残差からパネリストの個人差 $S_{\text{Panel}}$ を引き算できるため、誤差分散が劇的に小さくなり本物の差が検出できる！（発展課題5）
繰り返しなし・反復測定（Y ~ A + B）の平方和と自由度の分割
$$S_T = S_A + S_B + S_E, \qquad (ab - 1) = (a - 1) + (b - 1) + (a - 1)(b - 1)$$
理論最重要

2元配置分散分析の後の「多重比較」の分岐ルール

まず分散分析表の「交互作用（A:B）の $p$値」を見る！ そこからの進め方が2通りに分かれる

ルート①：交互作用が「有意でない」とき（$p_{A \times B} \ge 0.05$）

意味：要因Aと要因Bは互いに干渉せず、独立に効いている（折れ線が平行）。

多重比較の進め方：

  • 主効果が有意（$p < 0.05$）になった要因についてのみ、その要因単独で多重比較（Tukey-Kramer法など）を行う！
  • 要因A（例：温度2水準）と要因B（例：銘柄3水準）を別々に aov(Y ~ A)、aov(Y ~ B) で多重比較・CLD描画する。
  • ※ 練習1（植物種×肥料）・課題3（水温度×銘柄）はこちら！

ルート②：交互作用が「有意である」とき（$p_{A \times B} < 0.05$）

意味：片方の条件によってもう片方の効き方が変わる（相乗効果や逆転がある）。

多重比較の進め方：

  • 交互作用があるとき、主効果（全体の平均）だけを比較しても意味がない（または誤解を招く）。
  • paste(A, B, sep="") で要因Aと要因Bを連結し、全 $a \times b$ 個の試験区を1次元に展開してから Tukey-Kramer多重比較とCLD付与を行う！
  • ※ 練習2（薬×濃度6群）・課題2（土×肥料8群）・発展4（味×衣4群）はこちら！

FAQ

トラブルシューティング（第10回でよくあるエラーと対処法）

RStudioでエラーや警告が出たらここをチェック！

⚠️ read.csv("kadai1.tsv") で1列に潰れてしまう

原因：.tsv はタブ区切りファイル。
対策：read.delim("kadai1.tsv", stringsAsFactors = TRUE) を使う（日本語を含む kadai2.tsv 等は fileEncoding = "utf8" も指定）。

⚠️ 数値の水準（濃度 0.5, 1, 2）で自由度が 1 になる

原因：数値のみの列が因子（factor）ではなく連続変数（numeric）として扱われている。
対策：renshu2$Nodo <- as.factor(renshu2$Nodo) を実行してから aov() を行う。

⚠️ glht() で Completion with error > abseps 警告

原因：8群（28ペア）の多重比較で多変量t分布の数値積分の近似精度に関するWarningが出ることがある。
対策：エラーではなく計算結果やCLDには影響しないため、そのまま進めて問題ない。

⚠️ グラフの日本語が四角（□□□）に文字化けする（Mac）

対策：MacのRStudioでは plot() の直前に par(family = "HiraKakuProN-W6") を実行すると日本語がきれいに表示される。

本日の3大マスターポイント

1. 主効果と交互作用（Y ~ A * B）：単独の効果（主効果）だけでなく、組み合わせによる相乗効果（課題1）やクロスオーバー逆転効果（発展4）を検出できる。
2. 多重比較の分岐ルール：交互作用が非有意（$p \ge 0.05$）なら主効果ごとに比較し（課題3）、有意（$p < 0.05$）なら paste() で全試験区を展開してTukey法＋CLDで比較する（課題2・発展4）。
3. 反復測定・ブロック要因（Y ~ A + Panel）：評価者や被験者の個人差を分離することで誤差分散 $V_R$ を減らし、検出力を大幅に高められる（発展5）。

次回（第11回）への予告：ノンパラメトリック検定

第7回〜第10回で学んだ t検定や分散分析は、すべて「データが正規分布に従う」ことを前提としたパラメトリック検定でした。
では、極端な外れ値があるデータや、正規性検定（Shapiro-Wilk検定）で $p < 0.05$ となって正規分布が仮定できないデータはどう検定すればよいでしょうか？
データを「順位（ランク）」に置き換えて頑健に検定する第11回「ノンパラメトリック検定（Wilcoxon / Mann-Whitney / Kruskal-Wallis / Steel-Dwass）」をお楽しみに！
