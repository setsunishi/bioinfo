# 今日のゴール（What & Why）

### 「2つの要因（A×B）」を同時に比較し、相乗効果・相殺効果（交互作用）を検定する

- **1. 2元配置分散分析（Two-way ANOVA）の基本構造を理解する**
  - なぜ1要因ずつ別々に実験するより、2つの要因（例：土壌×肥料、薬剤×濃度）を組み合わせて同時に検定する方が優れているのか？
- **2. 「主効果（Main Effect）」と「交互作用（Interaction）」の違いを掴む**
  - 折れ線グラフ（交互作用プロット）が**「平行 ＝ 交互作用なし」**、**「非平行・交差 ＝ 交互作用あり（相乗効果や逆転現象）」**となる数理と視覚イメージ
- **3. 実験デザインに応じたRのモデル式（`*` と `+`）と多重比較を使い分ける**
  - **繰り返しあり（`Y ~ A * B`）**：交互作用が有意なら全組み合わせ（$a \times b$ 群）を展開して比較、非有意なら有意な主効果ごとに比較
  - **繰り返しなし / 対応あり反復測定（`Y ~ A + B`）**：個体差（ブロック要因）を分離して検出力を高める
- **4. 2つの「発見（Wow!）」体験で多要因解析の本質を体感する**
  - 【発見①】1要因ずつ見ると差がないのに、組み合わせると有意差が現れる**「クロスオーバー（逆転）交互作用」**（課題3）
  - 【発見②】評価者の個人差（`Panel`）を分離することで残差ノイズが半減し、隠れていた有意差が検出される**「多群の統計的ノイズキャンセリング」**（発展課題5）

# 【理論】なぜ「2元配置分散分析（Two-way ANOVA）」が必要なのか？

### 現実の生物・農学実験では「複数の要因」が同時に結果に影響している！

::: columns
::: {.column width="50%"}
### 第9回まで：1元配置（要因が1つだけ）
- 例1：肥料の種類（4群）だけでトマト糖度を比較
- 例2：飼料の種類（6群）だけでニワトリ体重を比較
- **限界**：「もし土壌の種類（土A vs 土B）が変わったら、肥料の効果はどう変わるのか？」という**要因間の組み合わせ効果**が分からない。
:::
::: {.column width="50%"}
### 第10回：2元配置（要因が2つ：要因A × 要因B）
- **例1（農学）**：**土壌の種類（A, B）× 窒素肥料の量（100, 200, 300, 400）**で作物収量はどう変わるか？
- **例2（薬理・生理）**：**薬品の種類（OJ, VC）× 投与濃度（0.5, 1, 2 mg）**で成長量はどう変わるか？
- **例3（食品科学）**：**味付け（普通, 辛口）× 衣の種類（普通, クリスピー）**でおいしさスコアはどう変わるか？
:::
:::

# 【理論】核心概念：「主効果（Main Effect）」と「交互作用（Interaction）」

### 「単独の効果（足し算）」なのか、「組み合わせによる相乗・相殺効果（掛け算）」なのか？

::: columns
::: {.column width="50%"}
### ① 主効果（Main Effects）
- **要因Aの主効果**：要因Bの水準を平均（無視）したときに、**要因Aの違いだけで平均値に差があるか**。
- **要因Bの主効果**：要因Aの水準を平均（無視）したときに、**要因Bの違いだけで平均値に差があるか**。
- 交互作用がない場合、各試験区の平均は「要因Aの効果 ＋ 要因Bの効果」という**単純な足し算（加法モデル）**で表せる。
:::
::: {.column width="50%"}
### ② 交互作用（Interaction：$A \times B$）
- **定義**：「一方の要因の水準によって、**もう一方の要因の効果（効き方・傾き）が変わること**」。
- **具体例**：
  - **相乗効果（Synergy）**：土壌Aでは肥料を増やしても少ししか収量が増えないが、**土壌Bでは肥料を増やすと爆発的に収量が増える**（課題1）。
  - **逆転・相殺効果（Crossover）**：**普通味には普通の衣が合い、辛口にはクリスピーな衣が合う**（ミスマッチだと不味くなる：発展課題4）。
:::
:::

# 【理論】視覚で一発判定！ 交互作用プロット（折れ線グラフ）の3パターン

### 「折れ線が平行なら交互作用なし」「傾きが違う・交差していれば交互作用あり！」

::: columns
::: {.column width="33%"}
### パターン①：交互作用なし（平行）
- 要因Bのどの水準でも、要因Aによる上昇幅（直線の傾き）が同じ。
- **折れ線がほぼ平行**に並ぶ。
- $\rightarrow$ 主効果Aと主効果Bをそれぞれ独立に評価・多重比較すればよい！（練習1・課題3）
:::
::: {.column width="33%"}
### パターン②：相乗的交互作用（非平行）
- 要因Aと要因Bが特定の組み合わせになったときだけ効果が急拡大する。
- **折れ線の傾きが大きく異なる（扇状に広がる）**。
- $\rightarrow$ 交互作用が有意！（練習2・課題1）
:::
::: {.column width="33%"}
### パターン③：逆転（クロスオーバー）交互作用
- 条件によって効果の向きが逆転し、**折れ線が「×（エックス）字」に交差**する！
- 左右の平均をとるとプラスとマイナスが打ち消し合い、**見かけ上「主効果がゼロ（非有意）」に見える**要注意パターン！（発展課題4）
:::
:::

# 【理論】実験デザインの分類：繰り返し「あり」と「なし（または対応あり）」

### 1つのマス（条件の組み合わせ）にデータが複数あるか、1つしかないかで解析法が変わる！

| 実験デザイン | 各マスのデータ数 $r$ | 検定できる効果 | Rのモデル式 | 代表例（本日のデータ） |
|:---|:---:|:---|:---:|:---|
| **① 繰り返しあり**<br>(With replication) | **$r \ge 2$ 個**<br>（複数反復あり） | ・要因Aの主効果<br>・要因Bの主効果<br>・**交互作用 $A \times B$** | **`aov(Y ~ A * B)`**<br>（アスタリスク `*`） | 練習1 (`renshu1.csv`)<br>練習2 (`renshu2.tsv`)<br>課題1, 課題3, 発展4 |
| **② 繰り返しなし**<br>(Without replication) | **$r = 1$ 個のみ**<br>（各マス1データ） | ・要因Aの主効果<br>・要因Bの主効果<br>（※**交互作用は検定不可**） | **`aov(Y ~ A + B)`**<br>（プラス `+`） | 練習3 (`renshu3.tsv`)<br>（温度4種×触媒3種＝12データ） |
| **③ 対応のある多群比較**<br>(反復測定：Repeated measures) | 各個体×各条件に<br>**$1$ 個** | ・処理要因Aの主効果<br>・個体差（被験者/パネル）<br>（※個体差ノイズを分離） | **`aov(Y ~ A + ID)`**<br>（プラス `+`） | 練習4 (`renshu4.tsv`：血圧)<br>**発展5 (`kadai3_2.tsv`：試食パネル)** |

# 【理論】変動（平方和）と自由度の分割（① 繰り返しありの場合）

### 総平方和 $S_T$ を「要因A」「要因B」「交互作用 $A \times B$」「残差（誤差）$R$」の4つに分割！

$$S_T = S_A + S_B + S_{A \times B} + S_R, \qquad (N - 1) = (a - 1) + (b - 1) + (a - 1)(b - 1) + (N - ab)$$

| 要因（R出力の行名） | 自由度 (`Df`) | 平方和 (`Sum Sq`) | 平均平方 (`Mean Sq`) | $F$値 (`F value`) | 検定の意味 |
|:---|:---:|:---:|:---:|:---:|:---|
| **要因 $A$**（水準数 $a$） | $df_A = a - 1$ | $S_A$ | $V_A = \dfrac{S_A}{a - 1}$ | **$F_A = \dfrac{V_A}{V_R}$** | 要因 $A$ の主効果の有無 |
| **要因 $B$**（水準数 $b$） | $df_B = b - 1$ | $S_B$ | $V_B = \dfrac{S_B}{b - 1}$ | **$F_B = \dfrac{V_B}{V_R}$** | 要因 $B$ の主効果の有無 |
| **交互作用 `A:B`** | $df_{A \times B} = (a-1)(b-1)$ | $S_{A \times B}$ | $V_{A \times B} = \dfrac{S_{A \times B}}{(a-1)(b-1)}$ | **$F_{A \times B} = \dfrac{V_{A \times B}}{V_R}$** | **$A$ と $B$ の相乗・相殺効果の有無** |
| **残差 `Residuals`（群内誤差）** | $df_R = N - ab$ | $S_R$ | $V_R = \dfrac{S_R}{N - ab}$ | — | 全 $F$検定の共通の分母（純粋な誤差） |
| **全体（Total）** | $df_T = N - 1$ | $S_T$ | — | — | — |

# 【理論】2元配置分散分析の後の「多重比較」の進め方（超重要ルール！）

### まず「交互作用 `A:B` の $p$値」を見る！ 有意かどうかで多重比較のルートが分岐する！

::: columns
::: {.column width="50%"}
### ルート①：交互作用が「有意でない」とき（$p_{A \times B} \ge 0.05$）
- 要因Aと要因Bは互いに干渉せず、独立に効いている。
- **手順**：主効果が有意（$p < 0.05$）となった要因についてのみ、**その要因の水準間で多重比較（Tukey-Kramer法など）**を行う。
- ※ 主効果が2水準（例：冷蔵庫 vs 常温）しかない場合は、ANOVAで有意と分かった時点で「平均が高い方が有意に高い」と結論できる。
:::
::: {.column width="50%"}
### ルート②：交互作用が「有意である」とき（$p_{A \times B} < 0.05$）
- 一方の要因によって他方の効き方が変わるため、**主効果（全体の平均）だけを比較しても意味がない（または誤解を招く）**！
- **手順**：要因A（$a$ 水準）と要因B（$b$ 水準）を結合して **全 $a \times b$ 個の試験区を1次元に展開**し（`paste(A, B, sep="")`）、全試験区間で **Tukey-Kramer多重比較とCLD付与**を行う！
:::
:::

# 【授業内練習 1】繰り返しあり・交互作用なし（`renshu1.csv`：植物種×肥料）

### 植物2種（`Species`: A, B）× 肥料3種（`Fertilizer`: X, Y, Z）の苗高（`Height`, cm）（各8反復, $N=48$）

::: columns
::: {.column width="50%"}
### Rコード：2元配置分散分析と多重比較
```r
renshu1 <- read.csv("renshu1.csv", stringsAsFactors = TRUE)
summary(renshu1)

# 繰り返しありの2元配置分散分析（アスタリスク * を使う！）
summary(aov(Height ~ Fertilizer * Species, data = renshu1))

# 交互作用なし(p=0.478) & Fertilizerのみ有意(p=0.000973)
# -> Fertilizer（3水準）についてTukey-Kramer多重比較
library(multcomp)
res1 <- aov(Height ~ Fertilizer, data = renshu1)
tukey1 <- glht(res1, linfct = mcp(Fertilizer = "Tukey"))
summary(tukey1)
cld(tukey1)
par(mar = c(5.1, 4.1, 6, 2.1))
plot(cld(tukey1))
```
:::
::: {.column width="50%"}
### 実行結果と解釈
- **分散分析表（`aov(Height ~ Fertilizer * Species)`）**：
  - `Fertilizer`（$df=2$）：**$F = 8.218, p = 0.000973$ (\*\*\*)** $\rightarrow$ 肥料の主効果あり！
  - `Species`（$df=1$）：$F = 1.587, p = 0.215$ $\rightarrow$ 植物種間の差なし
  - `Fertilizer:Species`（$df=2$）：**$F = 0.751, p = 0.478 (> 0.05)$** $\rightarrow$ **交互作用なし！**
  - `Residuals`（$df=42$）：$V_R = 8.81$
- **多重比較（ルート①）**：交互作用がなく `Fertilizer` のみ有意なので肥料3種を比較すると、CLDは **`X = "a", Y = "a", Z = "b"`**（肥料ZのみがX・Yより有意に苗高が高い）。

# 【授業内練習 2】繰り返しあり・交互作用あり（`renshu2.tsv`：薬品×濃度）

### 薬品2種（`Yaku`: OJ, VC）× 濃度3段階（`Nodo`: 0.5, 1, 2 mg）の成長量（`Growth`, g）（各10反復, $N=60$）

::: columns
::: {.column width="50%"}
### Step 1：読み込み・数値因子の変換・2-way ANOVA
```r
renshu2 <- read.delim("renshu2.tsv", stringsAsFactors = TRUE)
# 【重要】Nodoは数値(0.5, 1, 2)なので必ずfactorに変換する！
renshu2$Nodo <- as.factor(renshu2$Nodo)
summary(renshu2)

# 繰り返しありの2元配置分散分析
summary(aov(Growth ~ Yaku * Nodo, data = renshu2))
```
- **ANOVA結果**：
  - `Yaku` ($df=1$)：$F = 17.222, p = 0.000119$ (\*\*\*)
  - `Nodo` ($df=2$)：$F = 93.373, p < 2 \times 10^{-16}$ (\*\*\*)
  - **`Yaku:Nodo` ($df=2$)：$F = 4.499, p = 0.0156$ (\*) $\leftarrow$ 交互作用が有意！**
:::
::: {.column width="50%"}
### Step 2：交互作用あり $\rightarrow$ 6試験区に展開して多重比較！

# 【授業内練習 3】繰り返しなしの2元配置分散分析（`renshu3.tsv`：温度＋触媒）

### 各マスにデータが1つしかない場合（$r=1$）は `+` を使い、他要因の変動を分離する！

::: columns
::: {.column width="50%"}
### なぜ「繰り返しなし」だと交互作用が検定できないのか？
- 成型温度4水準（`T80, T90, T100, T110`）× 触媒量3水準（`S0.5, S1.0, S1.5`）＝ 全 $N = 12$ データ（1マス1個）。
- もし交互作用までモデルに入れると、残差自由度 $df_R = N - ab = 12 - 12 = 0$ となり、分母の誤差分散 $V_R$ が計算できなくなる！
- そこで「交互作用はない」と仮定し、$(a-1)(b-1) = 3 \times 2 = 6$ 自由度の変動を**誤差変動 $S_E$** として主効果を検定する（モデル式は **`Kyodo ~ Temp + Shoku`**）。
:::
::: {.column width="50%"}
### Rコード：温度 `Temp` を考慮することで触媒の差が見える！
```r
renshu3 <- read.delim("renshu3.tsv", stringsAsFactors = TRUE)
# 繰り返しなしの2元配置分散分析（+ を使う！）
res3 <- aov(Kyodo ~ Shoku + Temp, data = renshu3)
summary(res3)

# 温度もモデルに入れたまま触媒(Shoku)を多重比較
library(multcomp)
tukey3 <- glht(res3, linfct = mcp(Shoku = "Tukey"))
summary(tukey3); cld(tukey3)
```
- **注目**：もし温度を無視して1元配置 `aov(Kyodo ~ Shoku)` を行うと $p = 0.100$ で有意にならないが、`+ Temp` で温度変動（$p=0.0756$）を分離すると **`Shoku` が $F=5.842, p=0.0391$ (\*) で有意**になり、`S0.5 ("a")` と `S1.0 ("b")` の有意差（$p=0.0489$）が検出できる！
:::
:::

::: columns
::: {.column width="50%"}
### 第7回「対応のあるt検定」の3時点以上への拡張！
- 同じ被験者5名（A〜E）から3時点（`Mae`, `OneWeek`, `TwoWeeks`）の血圧を測定しているため、データには**「対応（個体差）」**がある。
- 数理的には「時間 `Time`（3水準）＋ 被験者 `ID`（5水準）の**繰り返しなし2元配置分散分析**」と同じ式 **`aov(mmHg ~ Time + ID)`** で、被験者の個人差（もともと血圧が高い人・低い人）を残差から引き算できる！
:::
::: {.column width="50%"}
### Rコード：反復測定ANOVAと `paired = TRUE` の多重比較
```r
renshu4 <- read.delim("renshu4.tsv", stringsAsFactors = TRUE)

                paired = TRUE, p.adjust.method = "bonferroni")
```
- **結果**：`Time` は $F = 35.51, p = 0.000105$ (\*\*\*) で極めて有意！
- 多重比較でも `Mae vs OneWeek` ($p = 0.0067$)、`Mae vs TwoWeeks` ($p = 0.0141$) が有意、`OneWeek vs TwoWeeks` ($p = 0.3647$) は差なし $\rightarrow$ 投薬1週間後から血圧低下効果が持続している！

### ⚠️ `.tsv` ファイルを `read.csv()` で読んで1列になってしまう
- **原因**: `.tsv` はカンマ区切りではなく**タブ区切り（Tab-Separated Values）**。
- **対策**: `read.delim("kadai1.tsv", stringsAsFactors = TRUE)` を使う（日本語を含む `kadai2.tsv`, `kadai3.tsv`, `kadai3_2.tsv` は `fileEncoding = "utf8"` も付ける）。

### ⚠️ 数値の水準（`Nodo` の `0.5, 1, 2` など）で交互作用の自由度がおかしい
- **原因**: 数字だけの列は `stringsAsFactors = TRUE` でも数値（連続変数）として読み込まれる。
- **対策**: `renshu2$Nodo <- as.factor(renshu2$Nodo)` で明示的に因子に変換してから `aov()` を実行する。
:::
::: {.column width="50%"}
### ⚠️ `glht()` で `Completion with error > abseps` というWarningが出る
- **原因**: 8群（28ペア）などの多重比較で多変量t分布の数値積分の近似誤差に関する通知が出ることがある。
- **対策**: 計算結果やCLDには影響しないため、そのまま進めて問題ない。

### ⚠️ グラフの日本語ラベルが豆腐（□□□）に文字化けする（Mac）
- **原因**: Mac版のR標準グラフィックデバイスで日本語フォントが指定されていない。
- **対策**: `plot()` の前に `par(family = "HiraKakuProN-W6")` を実行する（Windowsでは不要、または `par(family = "Meiryo")`）。

# 本日のまとめと次回（第11回・最終回）への予告

### 1. 本日マスターした3大ポイント
- **主効果と交互作用（Interaction）**: 2つの要因を同時に調べることで、単独の効果（主効果）だけでなく、組み合わせによる相乗効果（課題1）や逆転・相殺効果（発展4）を検出できる。
- **交互作用の有無による多重比較の分岐**: 交互作用が非有意（$p \ge 0.05$）なら有意な主効果ごとに比較し（課題3）、交互作用が有意（$p < 0.05$）なら `paste()` で全試験区を1次元に展開してTukey-Kramer法＋CLDで比較する（課題2・発展4）。
- **ブロック要因・反復測定（`Y ~ A + Panel`）の威力**: 評価者や被験者の個人差を2つ目の要因として分離することで、残差分散（ノイズ）を大幅に減らし検出力を高めることができる（練習3・練習4・発展5）。

### 2. 次回（第11回）への予告：もしデータが「正規分布に従わない」ときは？
- 第7回〜第10回で学んだ t検定や分散分析は、すべて「データが正規分布に従う」ことを前提とした**パラメトリック検定**でした。
- 次回（第11回）は、外れ値や歪んだ分布で正規性が仮定できないときにデータを「順位（ランク）」に変換して検定する**「ノンパラメトリック検定（Wilcoxon検定・Mann-Whitney U検定・Kruskal-Wallis検定・Steel-Dwass多重比較）」**を学びます！
