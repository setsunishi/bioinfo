【Wow体験 ①】

⚡ スナップショットの罠と「変化量（SW5_35）」の威力

出穂後5日（SW5）をA群とB群で比較しても有意差なし（$p = 0.139$）。出穂後35日（SW35）を直接比較しても有意差なし（$p = 0.258$）！
断面（スナップショット）だけ見ていると「遺伝子型AとBに差はない」と見逃してしまいます。

ところが個体ごとの減少量（SW5_35 = SW5 - SW35）を比較すると…
株ごとの初期サイズ（個体差ノイズ：SD $\approx 15\text{g}$）が引き算で半減（SD $\approx 8\text{g}$）し、さらに5日目と35日目の平均値の逆転が合算されて、
$\rightarrow$ $t = -4.95, p = 9.19 \times 10^{-6}$ へと $p$値が約28,000倍もシャープに浮き彫りになる！
【Wow体験 ②】

🍄 キノコ例題（$p = 0.05096$）で見る境界線F検定とWelchの知恵

斜面の上と下のキノコの長さ（kinoko.csv）で等分散性の検定 var.test() を行うと、なんと $p = 0.05096$（5%水準との差わずか $0.00096$！）という究極の境界線値が出ます。

なぜ「F検定 $\to$ t検定の二段階検定」は危険なのか？
同じデータに2回検定を行うと誤判定率が膨らみ（多重検定の罠）、$p=0.051$ と $0.049$ で手法が不連続に切り替わってしまいます。
$\rightarrow$ Welch検定は自由度を $127 \to 113.35$ へ滑らかに自動補正し、等分散・不等分散を問わず安全に使える現代標準！

📐 理論の3本柱（誤差の合成・F検定・Student vs Welch）

独立2群の検定を支える数理ロジック

1. 差の標準誤差は「足し算」

独立な2群の平均の差 $\bar{X}_1 - \bar{X}_2$ のばらつき（分散）は、個々の群の標準誤差の2乗和 $\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$ になる。サンプルサイズ $n_1$ と $n_2$ が異なっていても計算可能！

2. 等分散性の検定（F検定）

2群の不偏分散の比 $F = s_1^2 / s_2^2$ は自由度 $(n_1-1, n_2-1)$ の $F$分布に従う。Rの var.test() で $p > 0.05$ なら等分散とみなせる。

3. Student vs Welch

Student（var.equal=TRUE）は分散をプールし自由度 $n_1+n_2-2$。Welch（var.equal=FALSE）は不等分散にも対応し自由度を小数に補正。本授業では両方試して比較する！

⚠️ unused argument (paired = FALSE) エラー

チルダ演算子（~）を使った数式メソッド t.test(y ~ x) はそもそも独立2群専用のため、paired = FALSE オプションを同時に書くとエラーになります。paired 引数は削除（またはコメントアウト）してください。

⚠️ cannot open file 'kadai.txt' エラー

作業ディレクトリ（Working Directory）が kadai.txt の保存場所と一致していません。
RStudio メニューの Session $\rightarrow$ Set Working Directory $\rightarrow$ Choose Directory... で、ダウンロードした kadai.txt があるフォルダを選択してください。
