📖 演習の背景と本日のデータセット

背景知識

イネ76系統の分離集団において、出穂後の茎葉乾物重（穂以外の地上部重, SW）を測定しました。
今回は、1行に1系統が並んだスタック形式（縦持ち・タブ区切りテキスト kadai.txt）を用いて、Genotype A群（24系統：ジャポニカ型アレル）と Genotype B群（52系統：インディカ型アレル）という独立した2群の間で平均値が異なるかどうかを検定します。

データセット（クリックでダウンロード）：
・kadai.txt: イネ76系統データ（タブ区切り：Genotype, SW5, SW20, SW35, SW5_35）
・kinoko.csv: キノコ柄長データ（カンマ区切り：斜面上部 Ue 68本 vs 斜面下部 Shita 61本）
・kadai_独立2群の検定.xlsx: 課題説明付き元データExcelブック

課題1：SW5（出穂後5日の茎葉重）の遺伝子型間比較

基本検定（20点）

RStudioで以下のコードを実行し、出穂後5日の茎葉重（SW5）が Genotype（A vs B）ごとに異なるかどうかを検定してください。

kadai <- read.delim("kadai.txt", stringsAsFactors = TRUE) boxplot(kadai$SW5 ~ kadai$Genotype, ylab = "SW5 (g)") stripchart(kadai$SW5 ~ kadai$Genotype, vertical = TRUE, method = "jitter", add = TRUE) var.test(kadai$SW5 ~ kadai$Genotype) t.test(kadai$SW5 ~ kadai$Genotype, alternative = "two.sided", var.equal = TRUE) t.test(kadai$SW5 ~ kadai$Genotype, alternative = "two.sided", var.equal = FALSE)

発展課題4【Wow①：なぜ単一時点では差が見えず、変化量（SW5_35）で劇的な差が出たのか？】

探究課題（20点）
問い： 課題1（SW5: $p=0.139$）も課題2（SW35: $p=0.258$）も有意差がなかったのに、なぜ差をとった課題3（SW5_35: $p=9.19 \times 10^{-6}$）では約28,000倍もシャープな有意差が出たのでしょうか？
また、「Genotype B の減少量の方が Genotype A よりも大きい（すなわち $\mu_A - \mu_B < 0$）」ことを片側検定で検証してください。
# Rの因子順は第1群が A、第2群が B なので A - B < 0 は alternative = "less" t.test(kadai$SW5_35 ~ kadai$Genotype, alternative = "less", var.equal = FALSE) # 各変数の標準偏差 (SD) が引き算によってどう変化したかを確認 aggregate(cbind(SW5, SW35, SW5_35) ~ Genotype, data = kadai, FUN = sd)
