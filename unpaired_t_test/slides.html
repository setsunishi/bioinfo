前回のおさらい

第7回の復習：1群の検定・対応のあるt検定

前回のコアロジックを1枚で振り返る

仮説検定の基本ステップ（背理法）

  1. 帰無仮説 $H_0$：「差はない（$\mu_d = 0$）」と仮定する
  2. 検定統計量 $t$：観測された差を標準誤差（$SE = s/\sqrt{n}$）で割る
  3. $p$値の計算：自由度 $df = n-1$ の $t$分布の裾野の面積を求める
  4. 判定：$p < 0.05$ なら $H_0$ を棄却し「有意差あり」！

対応のある2群（Paired）のポイント

・同一のイネ個体の出穂後5日（SW5）と35日（SW35）のように、1対1のペア関係があるデータ。
・各個体の差 $d_i = \text{SW5}_i - \text{SW35}_i$ を計算することで、株ごとの個体差ノイズを相殺（ノイズキャンセリング）し、1標本のt検定に帰着させた！

理論

今回のお題：「対応のない2群（独立2群）」とは？

2つのグループの間で「メンバー（個体）が異なる」比較

🔗 対応がある2群（前回）

・薬品投与前の個体 A, B, C vs 投与後の同じ個体 A, B, C
・同一イネ系統の SW5 vs SW35
・特徴：上と下でメンバーが同じ。必ず $n_1 = n_2$。

⚔️ 対応がない2群 / 独立2群（今回！）

・薬品を添加したグループ（個体 A, B, C）vs 無添加の別グループ（個体 D, E, F, G）
・イネ Genotype A群（24系統）vs Genotype B群（52系統）
・特徴：メンバーが全く別（赤の他人）。サンプルサイズ $n_1$ と $n_2$ が異なっていてもOK！

💡 「品種A vs 品種B」「野生型 vs 変異体」「斜面上部 vs 斜面下部」など、実験科学の大部分はこの独立2群比較です！
理論

独立2群の検定における仮説のイメージ

2つの標本は「同じ母集団」から来たのか、「別々の母集団」から来たのか？

帰無仮説 $H_0$：$\mu_1 = \mu_2$（差がない）

「群1と群2の母平均は同じである（$\mu_1 - \mu_2 = 0$）」
手元の標本平均 $\bar{X}_1$ と $\bar{X}_2$ が違って見えるのは、同じ1つの母集団からたまたま偏って抽出された標本誤差にすぎない。

対立仮説 $H_1$：$\mu_1 \neq \mu_2$（差がある）

「群1と群2の母平均は異なる（$\mu_1 - \mu_2 \neq 0$）」
標本平均の違いは偶然の標本誤差ではなく、平均値が異なる2つの別々の母集団に由来する本物の差である。

理論

2つの平均値の差 $\bar{X}_1 - \bar{X}_2$ の誤差はどう分布する？

なぜ平均の「引き算」なのに、誤差の分散は「足し算」になるのか？

平均の差も $t$分布に従う！

・標本1の平均 $\bar{X}_1$ の誤差（$SE_1^2 = \sigma_1^2 / n_1$）も、標本2の平均 $\bar{X}_2$ の誤差（$SE_2^2 = \sigma_2^2 / n_2$）も正規分布・$t$分布に従う。
・したがって、2つの平均値の差 $\bar{X}_1 - \bar{X}_2$ の誤差も $t$分布に従う！

差の標準誤差（誤差の伝播法則）
$$SE_{\bar{X}_1 - \bar{X}_2} = \sqrt{SE_1^2 + SE_2^2} = \sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$$
独立な2群では、群1の不確実性と群2の不確実性が合算（足し算）される！

💡 直感的理解：なぜ「引き算」なのにルートの中は「足し算（$+$）」なの？

第7回（対応あり）では「同じ株の前後」を引いたため個体差が相殺されました。しかし今回の独立2群は赤の他人同士です。もし群1の平均がたまたま上振れ（$+$）し、群2の平均がたまたま下振れ（$-$）すると、引き算 $\bar{X}_1 - \bar{X}_2$ のズレは打ち消し合うどころか逆に拡大してしまいます。だから独立な2群の差ではブレ（分散）は常に足し算になります！

理論

独立2群の検定方法の選び方（全体マップ）

2つの母集団の「ばらつき（母分散 $\sigma_1^2, \sigma_2^2$）が等しいか」で2つの方法に分かれる

① 等分散の場合

Studentのt検定（var.equal = TRUE）
2群の山の幅が等しい（$\sigma_1^2 = \sigma_2^2$）と仮定し、両群の分散をプールして計算。

② 不等分散・不明の場合

Welchのt検定（var.equal = FALSE）
山の幅が違っても（$\sigma_1^2 \neq \sigma_2^2$）使える万能法。Rのデフォルト！

🔍 等分散性の検定

F検定（var.test）
2群の不偏分散の比 $F = s_1^2 / s_2^2$ から等分散性を検定する。

理論 ①

等分散を仮定した独立2群のt検定（Studentのt検定）

2群の母分散に差がない（$\sigma_1^2 = \sigma_2^2$）とみなせる場合
① 合同分散（プールされた不偏分散 $s_p^2$）
$$s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}$$
2群の不偏分散 $s_1^2, s_2^2$ を自由度で重み付け平均して1つにまとめる
② 検定統計量 $t$ と 自由度 $df$
$$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{s_p^2\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}}, \quad df = n_1 + n_2 - 2$$
自由度は全サンプル数 $n_1 + n_2$ から $2$ を引いた整数になる！

ポイント（式を丸暗記する必要はありません！）

Rの t.test(..., var.equal = TRUE) を実行すれば、上記の $t$値、自由度 $df = n_1 + n_2 - 2$、および $p$値が直接出力されます。$p < 0.05$ なら帰無仮説を棄却します。

理論 ②

等分散かどうかを検定するには？（F検定とF分布）

R.A. Fisher の $F$分布を用いて「分散の比」を検定する

等分散性の検定の仮説と統計量

  • 帰無仮説 $H_0$：2標本の母分散に差がない（$\sigma_1^2 = \sigma_2^2$）
  • 対立仮説 $H_1$：2標本の母分散に差がある（$\sigma_1^2 \neq \sigma_2^2$）
$$F = \frac{s_1^2}{s_2^2} \quad \text{（不偏分散の比）}$$

・$p > 0.05$ $\rightarrow$ 有意ではない（等分散とみなせる）
・$p < 0.05$ $\rightarrow$ 有意差あり（等分散とはいえない）

$F$分布の形（$t$分布との違いに注目！）

分散（2乗）の割り算なので負の値はとらず（$F \ge 0$）、$F = 1$ 付近を山として右に裾を引く非対称な分布になります（自由度は分子 $df_1 = n_1 - 1$, 分母 $df_2 = n_2 - 1$ の2つ）。

理論 ③

Welchの方法（等分散を仮定しないt検定）

母分散が等しいか不明でも、不等分散でも使える万能手法！
① Welch の検定統計量 $t$
$$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}$$
各群の標準誤差の2乗（$s_1^2/n_1$, $s_2^2/n_2$）を個別に足し合わせる
② Welch–Satterthwaite の近似自由度
$$df = \frac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1 - 1} + \frac{(s_2^2/n_2)^2}{n_2 - 1}}$$
近似式で補正するため、自由度 $df$ は整数になるとは限らない（小数になる）！
⭐ Welchの方法は等分散のデータに使っても全く問題ありません！ もともと等分散なら、Studentのt検定とほぼ同じ $p$値 になります（Rの t.test() のデフォルトも Welch です）。
重要コラム

【超重要】「多重検定の罠」と本授業の方針

なぜ現代では「F検定＋t検定の二段階検定」が推奨されないのか？

⚠️ 古い教科書の「二段階検定」の罠

古い教科書では「まず var.test() で等分散性を検定し、次に Student か Welch を行う」と説明されてきました。
しかし、同じデータに2回連続で検定を行うと、間違う確率（第1種の過誤）が単純計算で約2倍に膨らんでしまう（多重検定の罠）ため、現代の統計学では推奨されていません。

✅ 現代の対策と本授業での習慣づけ

・現代の実践対策：等分散性の検定は行わず、等分散性を問わず使える Welchのt検定だけを行うことが推奨されています。
・📘 本授業としてのルール：各手法の特徴と違いを深く理解するため、自分のデータ解析では「等分散性の検定（var.test）」も「2種類のt検定（Student / Welch）」も全部試して比較する習慣をつけましょう！

理論例題 1

例題1：等分散の場合の独立2群の比較（カジカの体重）

流域A（36個体, 平均62.5g, 分散15.3）vs 流域B（43個体, 平均64.5g, 分散16.3）
set.seed(314525) x1 <- rnorm(36, mean=62.6, sd=sqrt(15.3)) # 流域A (n=36) x2 <- rnorm(43, mean=64.5, sd=sqrt(16.2)) # 流域B (n=43) boxplot(x1, x2); stripchart(list(x1, x2), vertical=TRUE, method="jitter", add=TRUE) var.test(x1, x2) t.test(x1, x2, alternative="two.sided", paired=FALSE, var.equal=TRUE) t.test(x1, x2, alternative="two.sided", paired=FALSE, var.equal=FALSE)

① 等分散性の検定

$F = 0.9428$
$df_1 = 35, df_2 = 42$
$p = 0.8644 (> 0.05)$
$\rightarrow$ 等分散とみなせる

② Student (var.equal=T)

$t = -2.2004, df = 77$
$p = 0.03077 (< 0.05)$
95% CI: $[-3.768, -0.188]$
$\rightarrow$ 5%水準で有意差あり

③ Welch (var.equal=F)

$t = -2.2063, df = 75.287$
$p = 0.03042 (< 0.05)$
95% CI: $[-3.764, -0.192]$
$\rightarrow$ Studentとほぼ同じp値！

注意点

注意：2群のサンプルサイズが極端に離れている場合

例：$n_1 = 36$ と $n_2 = 3$ のような極端なアンバランス

⚠️ 極端なサンプルサイズ差の危険性

独立2群のt検定は $n_1 \neq n_2$ でも実行できますが、片方が極端に少ない（例：$n=36$ vs $n=3$）のは良くない実験デザインとされます。
・等分散性の検定（var.test）の検出力が著しく落ち、うまく判定できない可能性が高い。
・Student検定とWelch検定の乖離も激しくなる。

Rで確認してみるコード

x1 <- rnorm(36, mean=62.6, sd=sqrt(15.3)) x2 <- rnorm(3, mean=74.5, sd=sqrt(16.2)) var.test(x1, x2) t.test(x1, x2, var.equal=TRUE) t.test(x1, x2, var.equal=FALSE)

実験計画を立てるときは、可能な限り2群のサンプルサイズを揃える（または大きく離れすぎないようにする）のが鉄則です。

理論例題 2

例題2：等分散でない場合の独立2群比較（キササゲ実生）

地域A（42個体, 平均15.2cm, 分散1.1）vs 地域B（63個体, 平均12.7cm, 分散3.2）
set.seed(273006) x1 <- rnorm(42, mean=15.2, sd=sqrt(1.1)) # 地域A (n=42, 分散小) x2 <- rnorm(63, mean=12.7, sd=sqrt(3.2)) # 地域B (n=63, 分散大) var.test(x1, x2) t.test(x1, x2, alternative="two.sided", paired=FALSE, var.equal=FALSE)

① 等分散性の検定 (var.test)

・$F = 0.34651, \text{num } df = 41, \text{denom } df = 62$
・$p = 0.000486 (< 0.001)$
$\rightarrow$ 0.1%水準で有意となり、「等分散とはいえない（不等分散）」ことが示された！

② Welchのt検定 (var.equal=FALSE)

・$t = 8.9595, df = 101.67$（自由度が小数！）
・$p = 1.666 \times 10^{-14}$（1.666e-14）
・95%信頼区間：$[1.935, 3.035]$（0を含まない）
$\rightarrow$ 地域Aと地域Bの地上高は有意に異なる！

Rの基礎知識

コンピュータの「指数表示（e / E）」の読み方

$p$値が極めて小さいときに必ず登場する表記
🔢 RやExcelでは、$0$ がたくさん並ぶ極小値・極大値を aEb または aeb（$= a \times 10^b$） の形で表示します！

とても小さな数の例（$p$値など）

  • 1.666e-14 ＝ $1.666 \times 10^{-14}$
    （$= 0.00000000000001666$、有意水準 $0.05$ より圧倒的に小さい！）
  • 9.193e-06 ＝ $9.193 \times 10^{-6}$
    （$= 0.000009193 < 0.001$）

とても大きな数の例

  • 1.23e+05（または 1.23E+05）＝ $1.23 \times 10^5 = 123,000$
  • よくあるミス ❌：9.193e-06 の先頭の 9.193 だけを見て「$0.05$ より大きい！」と勘違いしないこと！ 後ろの e-06（$10^{-6}$） を必ず確認！
データ整形

実際の解析でのデータ形式：ワイド形式 vs スタック形式

なぜ独立2群では「スタック形式（縦持ち・1データ1行）」を使うのか？

❌ ワイド形式（横持ち・アンスタック）

Ue Shita 31.5 15.3 48.0 17.7 29.0 10.9

「対応がない」のに同じ行に並べるのは不自然で紛らわしい（ペアではない！）。さらに $n_1 \neq n_2$ だと行の長さが揃わず空白が出る。

⭕ スタック形式（ロング形式・縦持ち）

Shamen Length Ue 31.5 Ue 48.0 ... ... Shita 15.3

「1行＝1個体（1データ）」の大原則！
「分類ラベルの列（Shamen）」と「測定値の列（Length）」に分けて縦に積む。今後の分散分析（第9・10回）でも必須の形式！

Rの儀式

データの読み込みと「因子（Factor）化の儀式」

グループ列を単なる文字列（character）ではなく因子（factor）にする
# 方法1（推奨）：読み込む際に stringsAsFactors = TRUE を指定する kinoko <- read.csv("kinoko.csv", stringsAsFactors = TRUE) kadai <- read.delim("kadai.txt", stringsAsFactors = TRUE) # 方法2：読み込んだ後に as.factor() で因子型に変換する kinoko$Shamen <- as.factor(kinoko$Shamen)

なぜ stringsAsFactors = TRUE をつけるのか？

・Rに「Ue / Shita（A / B）は単なる文字列ではなく、データを分類するカテゴリ（因子 factor）である」と認識させるためです。
・R 4.0以降はデフォルトが FALSE（文字型）になりました。t.test だけなら文字型でも動くことがありますが、次回（第9・10回）の分散分析や多重比較（Tukey法）では因子型でないとエラーになるため、今から習慣づけましょう！

参考：条件にマッチする行を抜き出す方法

kinoko_ue <- kinoko[kinoko$Shamen == "Ue", ] kinoko_shita <- kinoko[kinoko$Shamen == "Shita", ]

※ ただし次のスライドの「チルダ ~」を使えば、わざわざ分割しなくても一発でグラフも検定もできます！

Rの核心文法

チルダ（~）演算子による層別プロットと検定

スタック形式ありがとう！ 目的変数 ~ 説明変数 で全てが統一される
✨ 数値列 ~ グループ列（例：kinoko$Length ~ kinoko$Shamen）と書くと、「左辺の測定値を、右辺の因子でグループ分けして解析せよ」という命令になります！
# ① 箱ひげ図＋ドットプロット boxplot(kinoko$Length ~ kinoko$Shamen) stripchart(kinoko$Length ~ kinoko$Shamen, vertical = TRUE, method = "jitter", add = TRUE) # ② 等分散性の検定 (F検定) var.test(kinoko$Length ~ kinoko$Shamen)
# ③ 等分散を仮定したt検定 (Student) t.test(kinoko$Length ~ kinoko$Shamen, alternative = "two.sided", var.equal = TRUE) # ④ 等分散を仮定しないt検定 (Welch) t.test(kinoko$Length ~ kinoko$Shamen, alternative = "two.sided", var.equal = FALSE)

📊 なぜ検定の前に必ず「箱ひげ図＋ドットプロット」を描くのか？
① 差の大きさ（何g / 何mm違うか＝効果量）を視覚的に把握するため　② t検定の前提条件である分布の対称性（正規性）や外れ値の有無を目視チェックするため！
⚠️ 注意：チルダ ~ を使う場合、paired オプションを指定するとエラーになります（独立2群専用のため）！

例題：キノコの柄の長さ（kinoko.csv）の検定結果

斜面上部（Ue, 68本）vs 斜面下部（Shita, 61本）の比較

・$F = 1.635, df = (60, 67)$
・$p = 0.05096 (> 0.05)$
・ぎりぎり有意ではない（等分散とみなせる）

Wow体験 ①

なぜ SW5 も SW35 も差がないのに、SW5_35 だと $p = 10^{-6}$ になるのか？

スナップショット比較の罠と、第7回×第8回の統合シナジー！

理由①：平均値の「逆転（交差）」現象

・5日目（SW5）：A群（$47.45\text{ g}$）$<$ B群（$53.13\text{ g}$）でBが $+5.67\text{ g}$ 大きい。
・35日目（SW35）：B群が激減して順位が逆転し、A群（$45.24\text{ g}$）$>$ B群（$41.29\text{ g}$）でAが $+3.95\text{ g}$ 大きい。
$\rightarrow$ 各時点の差は $4〜5.7\text{ g}$ でも、変化量の差は $5.67 + 3.95 = 9.63\text{ g}$ に倍増！

理由②：個体差ノイズが半減（SD: $15\text{g} \to 8\text{g}$）

・単一時点では系統ごとの初期サイズ差（SD $\approx 12〜15\text{ g}$）が $4\text{ g}$ の差をかき消す。
・個体内で SW5 - SW35 をとると初期サイズが相殺され、標準偏差が約半分（SD $\approx 8\text{ g}$）に縮小！
$\rightarrow$ 「分子が2倍・分母が半分」で $p$値が約28,000倍シャープに！

Wow体験 ① 発展

チルダ ~ での引き算の順序と片側検定（発展課題4）

なぜ課題3の $t$値 はマイナス（$-4.9457$）なのか？
# Genotype B の減少量が Genotype A より大きい（すなわち A - B < 0）ことを片側検定 t.test(kadai$SW5_35 ~ kadai$Genotype, alternative = "less", var.equal = FALSE)

Rの因子（Factor）順ルール

・Genotype の水準はアルファベット順で第1群が A（平均 $2.21\text{ g}$）、第2群が B（平均 $11.84\text{ g}$）。
・Rは (第1群 A) - (第2群 B) = 2.21 - 11.84 = -9.63 を計算するため、$t$値はマイナスになります。
・したがって「B群の方が減少量が大きい（$\mu_A - \mu_B < 0$）」を片側検定するには alternative = "less" を指定します！

🔍 発展課題4（片側検定）の実行結果を確認する

片側検定（alternative = "less"）の実行結果

・Welch片側検定：$t = -4.9457, df = 49.342$, $p = 4.596 \times 10^{-6}$（両側検定 $9.193 \times 10^{-6}$ のちょうど半分！）
・Student片側検定：$t = -4.7593, df = 74$, $p = 4.697 \times 10^{-6}$

Wow体験 ②

キノコ例題（$p = 0.05096$）に学ぶ「境界線F検定」とWelchの知恵

もし $p$値が $0.05096$ ではなく $0.049$ だったら？（発展課題5）

境界線 $p = 0.05096$ のジレンマ

・kinoko.csv の等分散性検定（var.test）は $F = 1.635, p = 0.05096$。
・有意水準 $0.05$ との差はわずか $0.00096$！
・もしキノコ1本の長さが $0.1\text{ mm}$ 変わって $p = 0.049$ になった途端に「等分散 $\to$ 不等分散」と別世界の手法にジャンプするのは不自然であり、二段階検定は第1種の過誤を増大させる（多重検定の罠）。

Welch検定の「連続的な自由度調整」

・Student検定：$df = 68 + 61 - 2 = \mathbf{127}$（分散の違いを無視）
・Welch検定：$df = \mathbf{113.35}$（分散比 $1.635$ に応じて自由度を約 $13.65$ 割り引いてペナルティ調整！）
・教訓：Welch検定は白黒を無理に決めつけず、ばらつきの不均衡を自由度で滑らかに吸収する優れた手法である！

FAQ

トラブルシューティング（よくあるエラーと対処法）

エラーが出ても慌てずここをチェック！

⚠️ unused argument (paired = FALSE)

原因：t.test(kadai$SW5 ~ kadai$Genotype, paired = FALSE) のように、チルダ ~ と paired オプションを同時に書いている。
対策：チルダ ~ を使う場合は paired オプションを書かない（削除またはコメントアウトする）。

⚠️ cannot open file 'kadai.txt'

原因：作業ディレクトリ（Working Directory）がずれている。
対策：RStudioの Session $\rightarrow$ Set Working Directory $\rightarrow$ Choose Directory... で kadai.txt があるフォルダを選択する。

⚠️ タブ区切りファイルを read.csv で読んだ

原因：kadai.txt はタブ区切りなのにカンマ区切り用の read.csv() を使うと1列に繋がってしまう。
対策：タブ区切りには read.delim("kadai.txt", stringsAsFactors=TRUE) を使う！

⚠️ 指数表記 9.193e-06 の入力方法

対策：Web課題の入力欄には 9.193e-06 や 9.19e-6、あるいは 0.00000919 のいずれの形式で入力しても正解と判定されます！
