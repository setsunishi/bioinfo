# 【理論】独立2群の検定における仮説設定

### 2つの標本は「同じ母集団」から来たのか、「異なる母集団」から来たのか？

- **実験状況**:
  - 群1（サイズ $n_1$）：標本平均 $\bar{X}_1$、不偏分散 $s_1^2$ （母平均 $\mu_1$、母分散 $\sigma_1^2$）
  - 群2（サイズ $n_2$）：標本平均 $\bar{X}_2$、不偏分散 $s_2^2$ （母平均 $\mu_2$、母分散 $\sigma_2^2$）
- **帰無仮説（$H_0$）**:
  - **2群の母平均に差はない（$\mu_1 = \mu_2$、すなわち $\mu_1 - \mu_2 = 0$）**
  - 「観測された標本平均の違い $\bar{X}_1 - \bar{X}_2$ は、同じ母集団からたまたま偏ってサンプリングされた標本誤差にすぎない」
- **対立仮説（$H_1$）**:
  - **2群の母平均に差がある（両側：$\mu_1 \neq \mu_2$ ／ 片側：$\mu_1 > \mu_2$ または $\mu_1 < \mu_2$）**
  - 「標本平均の違いは偶然の誤差ではなく、母平均が異なる2つの母集団に由来するためである」

# 【理論】2つの平均値の差 $\bar{X}_1 - \bar{X}_2$ のばらつき（標準誤差）

### 独立な2群の差をとると、ばらつき（分散）は「引き算」ではなく「足し算」になる！

::: columns
::: {.column width="50%"}
### 1群の標本平均のばらつき（復習）
- 群1の平均 $\bar{X}_1$ の標準誤差：$SE_1 = \sqrt{\frac{\sigma_1^2}{n_1}}$
- 群2の平均 $\bar{X}_2$ の標準誤差：$SE_2 = \sqrt{\frac{\sigma_2^2}{n_2}}$
- 各群の平均の誤差が正規分布・$t$分布に従うなら、**平均の差 $\bar{X}_1 - \bar{X}_2$ の誤差も $t$分布に従う！**
:::
::: {.column width="50%"}
### 差の標準誤差（誤差の伝播法則）
$$SE_{\bar{X}_1 - \bar{X}_2} = \sqrt{SE_1^2 + SE_2^2} = \sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$$
- **超重要ポイント**：
  - 対応がない場合、群1のブレと群2のブレは互いに打ち消し合わず、**分散が足し算（合成）**される！
  - この母分散 $\sigma_1^2, \sigma_2^2$ をどう推定するかで、**2種類のt検定（Student / Welch）**に分かれる！
:::
:::

# 【理論】2標本の検定方法の選び方（伝統的フローと現代標準）

### 母分散が未知のとき、「2群の母分散が等しいか（等分散性）」が論点になる

::: columns
::: {.column width="50%"}
### 1. 等分散を仮定する方法
- **Student の t検定（`var.equal = TRUE`）**
  - 前提：2群の母分散が等しい（$\sigma_1^2 = \sigma_2^2$）
  - 2群の分散を合算（プール）して計算
  - 自由度：$df = n_1 + n_2 - 2$（必ず整数）
:::
::: {.column width="50%"}
### 2. 等分散を仮定しない方法
- **Welch の t検定（`var.equal = FALSE`）**
  - 前提：母分散が等しいか不明、または不等分散（$\sigma_1^2 \neq \sigma_2^2$）でもOK
  - 各群の分散を個別に使って自由度を補正
  - **Rの `t.test()` のデフォルト設定！**
:::
:::

> **💡 等分散かどうかを調べる検定 ＝ F検定（`var.test()`）**
> 伝統的な教科書では「まずF検定で等分散性を調べてから Student か Welch かを選ぶ」と説明されてきました。まずはその両方の仕組みを順番に見ていきましょう！

# 【理論】等分散を仮定した独立2群のt検定（Studentのt検定）

### 2群の母分散が等しい（$\sigma_1^2 = \sigma_2^2 = \sigma^2$）と仮定できる場合

::: columns
::: {.column width="50%"}
### ① プールされた不偏分散（合同分散 $s_p^2$）
$$s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}$$
- 群1の不偏分散 $s_1^2$ と群2の不偏分散 $s_2^2$ を、それぞれの自由度（$n_1-1$, $n_2-1$）で重み付け平均して1つの共通分散にまとめる。
:::
::: {.column width="50%"}
### ② 検定統計量 $t$ と自由度 $df$
$$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{s_p^2\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}}$$
$$df = n_1 + n_2 - 2$$
- 2つの標本平均 $\bar{X}_1, \bar{X}_2$ を計算して拘束条件が2つあるため、自由度は全体のデータ数 $n_1 + n_2$ から $2$ を引いた整数になる！
:::
:::

# 【理論】等分散性をどうやって調べるか？（F検定とF分布）

### 2群の不偏分散の「比（割り算）」をとって検定する！

::: columns
::: {.column width="50%"}
### 等分散性の検定（F検定）の仮説
- **帰無仮説 $H_0$**：2群の母分散は等しい（$\sigma_1^2 = \sigma_2^2$、すなわち分散比 $= 1$）
- **対立仮説 $H_1$**：2群の母分散は異なる（$\sigma_1^2 \neq \sigma_2^2$）
- **検定統計量 $F$（分散比）**：
  $$F = \frac{s_1^2}{s_2^2}$$
  - 2群のばらつきが同じなら $F \approx 1$ になる
  - 大きく離れた値（$F \gg 1$ または $F \ll 1$）なら不等分散！
:::
::: {.column width="50%"}
### R.A. Fisher の $F$分布
- $F$値は、第1自由度（分子）$df_1 = n_1 - 1$、第2自由度（分母）$df_2 = n_2 - 1$ の **$F$分布** に従う。
- Rでは **`var.test()`** 関数で一発実行できる！
- **判定のしかた**：
  - **$p > 0.05$**：有意ではない $\rightarrow$ **等分散とみなせる**
  - **$p < 0.05$**：有意差あり $\rightarrow$ **等分散とはいえない（不等分散）**
:::
:::

# 【理論】等分散を仮定しない独立2群のt検定（Welchのt検定）

### 母分散が等しいか不明でも、不等分散でも使える万能アプローチ！

::: columns
::: {.column width="50%"}
### ① Welch の $t$ 統計量
$$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}$$
- 分散を無理にプールせず、それぞれの群の標準誤差の2乗（$s_1^2/n_1$ と $s_2^2/n_2$）をそのまま足し合わせる。
:::
::: {.column width="50%"}
### ② Welch–Satterthwaite の近似自由度
$$df = \frac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1 - 1} + \frac{(s_2^2/n_2)^2}{n_2 - 1}}$$
- 2群の分散の不均衡度合いに応じて自由度を割引補正する式。
- **だからWelch検定の自由度 $df$ は「小数（非整数）」になる！**
:::
:::

> **💡 等分散のデータに Welch を使っても大丈夫？**
> 全く問題ありません！ もともと等分散であれば、Studentのt検定とWelchのt検定の $p$値は**ほぼ同じ値**になります。

# 【超重要】「多重検定の罠」と本演習の方針

### なぜ現在では「F検定をせずに最初からWelch検定」が推奨されるのか？

::: columns
::: {.column width="50%"}
### ⚠️ 二段階検定（多重検定）の罠
- 古い教科書のやり方：「①まず `var.test()` で等分散性を検定 $\rightarrow$ ②その結果を見て Student か Welch を実行」
- **問題点**：同じデータに対して2回連続で検定を行うと、**誤判定（第1種の過誤）の確率が膨らんでしまう**（単純計算で約2倍近くになるリスク）。
- また、サンプルサイズが極端に小さい・偏っている（例: $n=36$ と $n=3$）と、そもそもF検定自体が正しく機能しない。
:::
::: {.column width="50%"}
### ✅ 現代の推奨と本授業のルール
- **現代統計学の推奨**：
  - 等分散性の検定はスキップし、等分散でも不等分散でも使える **Welchのt検定（`var.equal = FALSE`）を最初から使う**のが国際標準（だからRのデフォルトもWelch！）。
- **📘 本授業（演習）での習慣づけ**：
  - 学習のため、自分のデータ解析では **① `var.test()`（等分散性検定）、② Student（`var.equal=TRUE`）、③ Welch（`var.equal=FALSE`）の3つすべてを試して結果を比較する習慣**をつけましょう！
:::
:::

# 【理論例題1】等分散の場合の独立2群の比較（カジカの体重）

### スライドのRコードをコピペして、等分散時のStudentとWelchの一致を確認しよう

::: columns
::: {.column width="50%"}
### 例題1の設定
- 河川の鰍（カジカ）の体重：
  - 流域A：$n = 36$, 平均 $62.5\text{ g}$, 不偏分散 $15.3$
  - 流域B：$n = 43$, 平均 $64.5\text{ g}$, 不偏分散 $16.3$
```r
set.seed(314525)
x1 <- rnorm(36, mean=62.6, sd=sqrt(15.3))
x2 <- rnorm(43, mean=64.5, sd=sqrt(16.2))
var.test(x1, x2)
t.test(x1, x2, var.equal=TRUE)
t.test(x1, x2, var.equal=FALSE)
```
:::
::: {.column width="50%"}
### 実行結果の比較
- **等分散性の検定 (`var.test`)**:
  - $F = 0.9428, df_1 = 35, df_2 = 42, p = 0.8644 (> 0.05)$
  - $\rightarrow$ 有意ではない（等分散とみなせる）
- **Studentのt検定 (`var.equal=TRUE`)**:
  - $t = -2.2004, df = 77, p = 0.03077$
- **Welchのt検定 (`var.equal=FALSE`)**:
  - $t = -2.2063, df = 75.287, p = 0.03042$
- $\rightarrow$ **等分散のとき、両者の $p$値（約 $0.031$ vs $0.030$）はほぼ完全に一致し、どちらも5%水準で有意！**
:::
:::

# 【理論例題2】不等分散の場合の独立2群の比較（キササゲの実生）

### 2群のばらつきが大きく異なるときは Welch の独壇場！

::: columns
::: {.column width="50%"}
### 例題2の設定
- 楸（キササゲ）実生の地上高（cm）：
  - 地域A：$n = 42$, 平均 $15.2\text{ cm}$, 不偏分散 $1.1$
  - 地域B：$n = 63$, 平均 $12.7\text{ cm}$, 不偏分散 $3.2$
```r
set.seed(273006)
x1 <- rnorm(42, mean=15.2, sd=sqrt(1.1))
x2 <- rnorm(63, mean=12.7, sd=sqrt(3.2))
var.test(x1, x2)
t.test(x1, x2, var.equal=FALSE)
```
:::
::: {.column width="50%"}
### 実行結果と読み解き方
- **等分散性の検定 (`var.test`)**:
  - $F = 0.3465, df_1 = 41, df_2 = 62, p = 0.000486 (< 0.001)$
  - $\rightarrow$ **0.1%水準で有意（等分散とはいえない！）**
- **Welchのt検定 (`var.equal=FALSE`)**:
  - $t = 8.9595, df = 101.67, p = 1.666 \times 10^{-14}$
  - 95%信頼区間：$[1.935, 3.035]$（0を含まない）
- **指数表示の読み方**：
  - `1.666e-14` ＝ $1.666 \times 10^{-14}$（小数点以下に0が13個並ぶ極小値！）
:::
:::

# 【実践】データ形式の重要ルール：ワイド形式 vs スタック形式

### 対応がない2群のデータは「スタック形式（縦持ち・1データ1行）」で扱う！

::: columns
::: {.column width="50%"}
### ❌ ワイド形式（横持ち）が紛らわしい理由
```text
Ue     Shita
31.5   15.3
48.0   17.7
29.0   10.9
```
- 対応のあるデータ（同一株の5日目と35日目）なら同じ行に並ぶ意味がある。
- しかし**独立2群（斜面上部のキノコ vs 下部のキノコ）では、1行目の31.5と15.3にペア関係は一切ない**し、サンプル数が違うので空白も出てしまう！
:::
::: {.column width="50%"}
### ⭕ スタック形式（ロング形式・縦持ち）
```text
Shamen  Length
Ue      31.5
Ue      48.0
...     ...
Shita   15.3
Shita   17.7
```
- **「1行＝1個体（1測定データ）」**の原則！
- 1列目に分類ラベル（因子 `Factor`: `Shamen` や `Genotype`）、2列目以降に数値（`Length`, `SW5` など）を配置する。
- これからの分散分析（第9・10回）でも**すべてこのスタック形式が標準**になります！
:::
:::

# 【実践】スタック形式データの読み込みと「因子（Factor）化の儀式」

### グループ分けの列（文字列）を R に「分類因子（Factor）」として認識させる

```r
# CSVファイルの読み込み（例題：kinoko.csv）
kinoko <- read.csv("kinoko.csv", stringsAsFactors = TRUE)

# タブ区切りテキストの読み込み（本日の課題：kadai.txt）
kadai <- read.delim("kadai.txt", stringsAsFactors = TRUE)
```

- **`stringsAsFactors = TRUE` の役割（超重要！）**:
  - 文字型の列（`"Ue"` / `"Shita"` や `"A"` / `"B"`）を、単なる文字列（`character`）ではなく、グループ分けを表す**因子型（`factor`）**として自動で読み込むオプション。
  - もし `read_csv()` 等で `character` になった場合は、`kinoko$Shamen <- as.factor(kinoko$Shamen)` で変換できる。

# 【実践】魔法の演算子「チルダ `~`」による層別プロットと検定

### `目的変数（数値） ~ 説明変数（グループ因子）` の統一文法！

::: columns
::: {.column width="50%"}
### チルダ（`~`）の意味
- **`Y ~ X`** ：「数値 `Y` をグループ因子 `X` ごとに分類して扱う」というRのモデル式記法。
- 一度スタック形式で読み込めば、**作図も等分散検定もt検定もすべて同じ `Y ~ X` の形**で書ける！
- ⚠️ **注意**：チルダ `~` を使う場合、そもそも独立群の比較専用なので `paired = FALSE` オプションを書くとエラーになる（省略するのがルール）！
:::
::: {.column width="50%"}
### 4点セットの黄金テンプレート
```r
# ① 箱ひげ図＋ドットプロット

# ③ Studentのt検定 (等分散仮定)
t.test(kinoko$Length ~ kinoko$Shamen, var.equal=TRUE)

# ④ Welchのt検定 (等分散仮定しない)

```

### 理由1：平均値の「逆転（交差）」現象

# 【Wow①発展】片側検定と R のグループ順序のルール

### Rでチルダ `~` を使ったとき、引き算の順番はどう決まるのか？

```r
# Genotype B の減少量の方が Genotype A より大きい（すなわち A - B < 0）を片側検定
t.test(kadai$SW5_35 ~ kadai$Genotype, alternative = "less", var.equal = FALSE)
```

- **Rの因子（Factor）の並び順ルール**:
  - アルファベット順で第1群が **`A`**（平均 $2.21\text{ g}$）、第2群が **`B`**（平均 $11.84\text{ g}$）になる。
  - したがって、Rは内部で **`(Aの平均) - (Bの平均) = 2.21 - 11.84 = -9.63`** を計算している（だから両側検定の $t$値 もマイナス `-4.9457` になっている！）。
- **片側検定の指定**:
  - 「B群の方が減少量が大きい」$\iff$「A群の平均 $<$ B群の平均（`A - B < 0`）」なので、**`alternative = "less"`** を指定する。
  - 結果：**$p = 4.596 \times 10^{-6}$**（両側検定 $9.193 \times 10^{-6}$ のちょうど半分！）。

# 【Wow②】キノコ例題（$p = 0.05096$）に学ぶ「境界線F検定」とWelchの知恵

### もし `var.test()` の $p$値が $0.05096$ ではなく $0.049$ だったら結論は変わるのか？

# 本日のまとめと次回（第9回）への予告

### 1. 本日マスターした3大ポイント
- **独立2群のt検定（Student vs Welch）**: 異なる個体群（$n_1 \neq n_2$ 可）の比較では、等分散を仮定するStudent法と仮定しないWelch法があり、「多重検定の罠」を避けるためWelch法が現代の標準であること。
- **スタック形式とチルダ（`~`）記法**: 1データ1行のスタック形式と `目的変数 ~ 説明変数` の文法で、作図・`var.test()`・`t.test()` を自在に実行できること。
- **スナップショットの罠と変化量解析**: 単一時点（SW5, SW35）では個体差ノイズに埋もれて見えない遺伝子型間の差も、個体内変化量（`SW5_35`）を比較することで劇的な検出力（$p = 10^{-6}$）で証明できること。

### 2. 次回（第9回）への予告：もしグループが「3群以上」あったらどうする？
- 今日までは「2群」の比較でした。では、**「品種A vs 品種B vs 品種C」や「対照区 vs 低濃度 vs 中濃度 vs 高濃度」のように3群以上**あるとき、t検定を何回も繰り返してよいのでしょうか？
- $\rightarrow$ **実はt検定を繰り返すと「多重検定の罠」で偽陽性が大爆発します！**
- 次回、**第9回「検定③：1元配置分散分析（One-way ANOVA）と多重比較（Tukey / Dunnett）」**をお楽しみに！
